# 통계와 순위의 숫자 표시

## 원인

교사 대시보드의 학생별 통계에서 총 질문 수 열은 48픽셀로 지정되어 있었다. 셀의 좌우 여백 32픽셀을 제외한 좁은 공간에 공통 줄바꿈 스타일이 적용되면서 `12`도 두 줄로 나뉘었다.

대시보드 비율 막대의 `100%`, 질문 분류 통계의 `12 (100%)`, 휴대전화 순위표의 포인트에서도 고정 폭과 줄바꿈 스타일이 같은 문제를 일으켰다.

## 표시 기준

- 학생별 총계 열은 최소 폭을 확보하고 수량 셀은 숫자 전체를 한 줄로 표시한다.
- 숫자에 `whitespace-nowrap`과 `tabular-nums`를 적용한다. 가로 배치에서는 필요한 경우 `shrink-0`으로 숫자가 눌리지 않도록 한다.
- 비율·포인트 값은 고정 폭 대신 최소 폭을 사용해 자리 수에 따라 공간을 확보한다.
- 좁은 화면의 통계 카드는 도넛 차트와 분류별 수치를 위아래로 배치해 값을 읽을 공간을 확보한다.
- 교사·학생 대시보드, 질문 분류 통계, 순위표, 포인트, 학생 관리 통계 및 수량 배지에 적용한다.

## 검증

- 교사·학생 대시보드: 375·768·1024·1440픽셀, 총계 `12`, `123`, `1234`, `12345`와 `100%`.
- 질문 분류 통계와 순위표: 375·1024·1440픽셀, `12 (100%)`, 포인트와 순위의 여러 자리 숫자.
- 기존 질문 목록: 교사·학생의 좋아요·댓글 개수 표시 검증 유지.
- 브라우저에서 실제 글자의 위치를 측정해 한 줄 표시, 잘림과 영역 이탈 여부를 확인하고 페이지 전체의 가로 넘침도 검사한다.
