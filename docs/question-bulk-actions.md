# 선택한 질문 작업과 맞춤 댓글

교사 페이지의 **질문탐구 → 전체 질문 목록**에서 질문을 체크하면 목록 안에 작은 작업 표시줄이 나타난다.

## 사용 흐름

1. 질문을 선택한다. 표시줄에서 선택한 질문 개수를 확인한다.
2. **맞춤 댓글 작성**을 누르면 목록 안에 맞춤 댓글 패널이 펼쳐진다.
3. **댓글 생성하기**를 누르면 선택한 질문별로 인공지능 댓글을 생성한다.
4. 기존 미리보기 창에서 댓글을 확인·수정하고 등록 대상을 확인한다.
5. **댓글 등록**을 누르면 학생 질문에 댓글로 저장한다.

질문 선택과 패널 열기만으로는 댓글을 생성하거나 등록하지 않는다.

## 선택과 패널의 동작

- **패널 닫기**: 패널만 접고 선택한 질문은 유지한다. 키보드 초점은 맞춤 댓글 작성 버튼으로 돌아간다.
- **선택 해제**: 질문 선택과 패널을 함께 초기화한다.
- 선택을 모두 해제하거나 등록 후 선택이 정리되면, 다음 선택에서는 패널을 닫힌 상태로 시작한다.
- 수업·필터·페이지·탭이 바뀌면 기존 선택과 패널을 초기화한다.
- 패널을 닫은 뒤 같은 선택을 엑셀 다운로드나 수업 화면 보기에 사용할 수 있다.
- **더보기 → 선택한 질문 삭제**에서 삭제를 시작하며 기존 삭제 확인 창을 유지한다.
- 생성·등록·삭제 중에는 중복 작업과 패널 닫기를 막는다.

휴대전화와 컴퓨터에서 패널 열기·닫기, 생성과 등록, 선택 유지, 삭제 확인, 조회 범위 변경을 자동 검사한다.

## 댓글 작성자 구분

- 교사·학생 공통 댓글 화면에서 로그인한 계정으로 작성한 글은 옅은 파란색 배경과 테두리, **내 댓글** 표시로 구분한다.
- 이름이 아닌 작성자 계정으로 비교하므로 동명이인의 댓글은 본인 글로 표시하지 않는다.
- 다른 사람의 댓글은 기본 배경을 유지하며, 부적절 의심 댓글은 경고 색상을 우선한다. 본인 글이면 **내 댓글** 표시도 함께 유지한다.
- 교사가 인공지능 초안을 검토해 등록한 댓글도 교사 본인이 작성한 댓글로 표시한다.
- 밝은 화면과 어두운 화면 모두 적용하며 댓글의 순서는 유지한다.
