# 수업별 성장 기록과 교사 연습 추천 안내

## 수업별 성장 기록

학생 상세 리포트와 교사가 보는 학생별 리포트의 질문수업별 분석을 펼치면 해당 학생·수업의 성장 기록을 함께 보여 준다. 분석 결과가 없어도 성장 기록은 조회할 수 있다.

- 학생이 직접 작성한 질문을 만들거나 고친 점 또는 배운 점이 있는 기록만 조회한다. 질문 수정 과정에서 질문만 자동 저장된 기록은 이 목록에서 제외한다.
- 질문을 수정한 기록에는 실제 보관된 처음 질문과 고친 질문을 나란히 보여 준다. 좁은 화면에서는 위아래로 배치한다. 질문을 수정하지 않았다면 나의 질문 하나만 표시한다.
- 질문 문장을 다시 입력하게 하지 않고 저장된 내용을 연결한다. 학생은 질문 작성 후 질문을 만들거나 고친 점, 탐구 후 배운 점을 각각 선택적으로 남길 수 있다.
- 돌아보기와 배운 점은 학생이 작성한 내용을 그대로 표시한다. 빈 항목과 작성 전 안내 문구는 기록 내용에 포함하지 않는다.
- 수업 안의 검색·상태 필터, 하단 전체 모아보기와 상단 바로가기를 제거하여 수업별 분석에서 기록을 읽도록 정리한다.
- 기록이 많으면 최근 수정 순으로 8개씩 페이지를 바꾸어 읽는다. 학생은 기존 나의 질문 화면에서 이어 쓸 수 있다. 담당 교사는 조회만 가능하다.
- 직접 쓴 내용이 없으면 해당 수업에 아직 기록이 없다는 안내만 표시한다. 기존 데이터는 삭제하지 않는다.

## 자료와 권한

수업별 조회에는 수업 식별자가 반드시 필요하다. 학생 본인 또는 담당 교사 권한을 먼저 확인한 뒤 학생·수업·직접 작성 여부를 함께 제한한다. 수업을 누락한 요청은 전체 조회로 전환하지 않고 거절한다. 수업을 펼칠 때만 조회하며 다른 수업이나 학생으로 바꾸면 페이지 상태를 초기화한다.

기존 질문과 성장 기록 저장 절차, 버전 충돌 처리, 포인트를 유지한다. 데이터베이스 구조 변경과 더미 자료 재생성은 없다. 이전 화면 및 질문 작성 흐름의 기존 조회 방식은 호환성을 위해 유지한다.

## 교사 연습 추천 안내

교사 추천은 풀이 기록 추가 필요, 유형별 보충 연습 추천, 질문 바꾸기 연습 추천으로 구분하고 이유를 함께 표시한다. 추천 기준 보기에 최근 30일·학생별 최신 100회, 반복 풀이 집계, 유형별 3회와 정답률 80% 기준을 설명한다. 추천 알고리즘은 그대로 유지한다.

긴 추천 설명은 휴대전화와 태블릿에서 학생별 카드 한 줄 전체를 사용한다. 풀이 횟수는 줄바꿈하지 않는다. 한국어·영어 및 밝은·어두운 테마를 지원한다.

## 검증 범위

- 학생·수업 제한, 수업 누락 시 거절, 직접 작성한 내용과 자동 저장 기록 구분
- 검색과 하단 목록 제거, 작성 내용 즉시 표시, 미작성 항목 숨김, 여러 쪽 조회
- 분석 결과가 없는 수업, 학생 이어쓰기 및 교사 조회 권한
- 기존 질문 저장·필터·언어·탐구설계·질문놀이 동작
- 전체 자동 검사와 커버리지 기준, 타입·정적 검사, 데이터베이스 호환성 및 운영용 빌드

검증 결과: 전체 자동 검사 364개 파일·3,591개 항목 및 커버리지 기준 통과. 브라우저 43개 항목 통과: 처음 질문·고친 질문 비교, 수정하지 않은 질문의 단일 표시, 네 항목 연결, 부분 작성과 기존 질문 작성·필터·언어 흐름을 확인했다. 타입·정적 검사, 데이터베이스 스키마·접근 보안 검사와 운영용 빌드도 통과했다.
