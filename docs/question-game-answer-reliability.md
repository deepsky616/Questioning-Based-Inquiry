# 질문놀이 판정 오류 개선

## 확인한 문제와 수정

| 대상 | 오류 원인 | 적용한 개선 |
| --- | --- | --- |
| 미스터리박스 | 일부 후보만 색상 정보가 있어 나머지는 기본 색깔 질문도 판정 보류 응답으로 끝남 | 후보 48개에 놀이용 대표 색상 부여, 기본 색깔 질문을 서버에서 직접 판정 |
| 미스터리박스 | 띄어쓰기·색깔이라는 접두 표현·색 형용사에 따라 같은 뜻의 질문이 다른 경로로 이동 | 검은색·검정색·까만색, 색깔이 주황색, 빨갛나요, 부정 질문 등 완전한 한 문장 표현 지원 |
| 까바놀이 | 제한된 서술어 목록 때문에 올바른 해요체나 색 이름을 오답 처리 | 원문 25개의 해요체와 빨간색·파란색·흰색 표현 추가, 원문과 다른 색·대상·부정 의미는 구분 |
| 이야기 주사위 | 감정 단어를 먼저 찾으면서 이유·사람·때를 묻는 질문도 감정 질문으로 분류 | 왜·누구·언제·어디를 우선 분류하여 관련성 검토에 실제 질문 의도 전달 |
| 여러 놀이의 공통 입력 | 일부 물음 어미, 영어 완료형 질문, 분리된 한글 입력을 인식하지 못함 | 한글 정규화와 까·죠·지요, 영어 완료형 등의 질문 시작 표현 보완 |

질문 주사위·질문 릴레이·질문 사다리·이야기 주사위는 공통 질문 형식 검사를 사용한다. 질문·대답 짝 찾기는 입력 문장의 예·아니오 판정 대신 카드의 짝 식별값을 비교하며, 이 경로도 회귀 검증에 포함한다.

## 학생에게 알려 줄 색깔 기준

- 미스터리박스 질문 입력 근처의 **색깔 질문의 기준 보기**를 열면 모든 후보의 대표 색상을 확인할 수 있다.
- 여러 색이 적힌 후보는 그중 하나를 물으면 예, 없는 색을 물으면 아니요로 답한다.
- 이 표는 놀이에서 정한 대표 모습이며 실제 품종·제품의 모든 색을 뜻하지 않는다. 기기별 이모지 색에도 의존하지 않는다.
- 안내를 열고 닫아도 작성 중인 질문이 유지된다. 혼자 하기, 인공지능 대결, 친구 방에서 같은 기준을 사용한다.
- 자유로운 표현을 인공지능으로 검토할 때에도 모든 후보의 같은 색상 표를 두 번의 독립 판정에 제공한다. 개별 부위의 색이나 복합 조건을 전체 색상과 같다고 단정하지 않는다.

## 기존 기록과 점수 보존

- 미스터리박스 새 색깔 답변은 근거 버전 3으로 저장한다. 기존 근거 버전 1·2는 이전 기준으로 검증하며, 기존 인공지능 차례 계획도 유지한다.
- 새 색깔 단서만 새 기준으로 인공지능 정답 후보에 반영한다.
- 까바놀이의 새 친구 방 시도에는 판정 버전 2를 기록한다. 버전이 없는 이전 정답·오답은 버전 1로 읽는다.
- 정답을 포함한 서버 비공개 상태는 계속 숨긴다. 색상 안내는 모든 후보에게 동일하게 공개하는 규칙이다.
- 불확실한 자유 질문은 기존처럼 작성 내용을 유지하고 다른 특징을 묻도록 안내한다. 미스터리박스 질문 횟수와 점수를 소비하지 않는다.

## 재발 방지 검증

- 모든 후보에 대한 12가지 색, 한국어·영어의 답 일치와 부정 질문 확인.
- 기본 색깔 질문을 외부 인공지능 연결 없이 저장·재요청·재접속·정산할 수 있는지 확인.
- 혼자 하기와 인공지능 대결, 친구 방의 다음 차례와 공개 상태 복원 확인.
- 까바놀이 원문 25개와 같은 뜻의 새 질문, 이전 오답 기록 및 변조 기록 구분 확인.
- 7종 놀이의 브라우저 진행·재접속·이탈·중복 요청·점수 처리 검증.
- 좁은 화면과 밝은 화면·어두운 화면에서 색깔 안내를 열고 닫아도 입력을 유지하고 가로 넘침이 없는지 확인.

외부 인공지능 응답은 자동 테스트에서 통제된 응답으로 대체한다. 일반 색깔 질문은 실제 서버 규칙으로 검증하며, 다양한 자유 질문의 실제 모델 응답 품질을 모두 보장하는 검사는 아니다.
