# 성장 기록 상태, 출력, 분석 정보와 시연 댓글 개선

학생의 내 질문에서 질문을 만들거나 고친 점과 탐구하며 알게 된 점을 모두 작성한 기록은 `성장 기록 보기·수정`으로 표시한다. 둘 중 하나라도 비어 있으면 `성장 기록 이어쓰기`를 유지한다. 공백만 있는 입력은 작성으로 계산하지 않는다. 질문 목록에서 본인 기록의 완료 여부만 함께 조회하며 성장 기록 본문을 다른 학생의 질문 목록에 제공하지 않는다. 저장 성공 시 본인의 질문 목록을 갱신하고 수업별 성장 기록에서도 같은 문구를 사용한다.

완료한 기록은 초록색 글씨와 확인 아이콘, 미완성 기록은 파란색 글씨와 연필 아이콘으로 구분한다. 밝은 테마에는 진한 글씨와 연한 배경, 어두운 테마에는 밝은 글씨와 진한 배경을 적용한다. 공용 링크를 사용해 휴대전화·데스크톱의 내 질문과 수업별 기록에서 표시를 맞춘다. 키보드 초점 표시와 최소 44픽셀 높이를 제공하고 전역 다크 테마 변환 규칙이 개별 색상을 덮어쓰지 않도록 한다.

작성 양식은 처음 질문·고친 질문을 윗줄에, 질문을 만들거나 고친 점·탐구하며 알게 된 점을 아랫줄에 배치한다. 640픽셀 이상 화면에서는 2×2, 좁은 화면에서는 한 열로 표시한다. 질문을 고치지 않았으면 고친 질문 칸에 안내를 표시하고 문장을 중복하지 않는다. 두 메모는 선택 작성이며 역할이 다른 설명과 예시를 제공한다. 작성 화면·수업별 기록·교사 출력물의 한국어 및 영어 항목명을 통일하고 기존 저장 필드와 작성 내용은 유지한다.

교사의 학생 개별 출력은 출력 직전에 최신 학생 리포트를 조회한다. 전체 학생 출력도 학생마다 직접 작성한 성장 기록을 해당 수업에 연결한다. 화면의 현재 페이지나 접힌 상태에 관계없이 전체 기록을 포함한다. 인공지능 분석이 없는 수업도 성장 기록이 있으면 출력한다. 자동 보관만 된 질문과 비어 있는 메모는 생략하며, 입력한 원문은 그대로 출력한다. 조회 실패 시 미리보기를 열지 않고 다시 시도할 수 있는 안내를 표시한다.

질문수업별 목록은 인공지능 분석 여부와 유효한 최근 분석일을 보여 준다. 교사는 `분석 정보`를 펼쳐 저장된 분석 모델을 확인할 수 있다. 모델 정보가 없으면 추정하지 않는다. 학생 화면과 출력물에는 모델명을 표시하지 않는다. 분석 정보는 기본적으로 접혀 있으며 키보드로 펼칠 수 있다.

시연 댓글은 질문에 맞는 답변, 근거, 다른 관점, 후속 질문을 서로 다르게 배치한다. `scripts/refresh-demo-comments.mjs`는 기존 시연 댓글의 식별자와 문장을 확인해 학생이 직접 추가하거나 수정한 댓글을 보존한다. 질문·작성자·날짜·포인트·성장 기록을 유지하고, 기존 포인트에 연결된 댓글은 중복 지급 방지 해시도 함께 갱신한다. 비공개 백업과 원본 복원 검증 후 적용했으며, 기존 자료 전체를 다시 생성하지 않았다.

실제 시연 댓글 183개를 서로 다른 183개 문장으로 변경했다. 포인트 연결 2건의 해시만 문장에 맞게 갱신했으며 포인트 금액과 성장 기록은 보존했다. 보호 규칙은 트랜잭션 안에서 복원하고 적용 전후 상태를 검사했다. 같은 작업을 다시 미리보기 하면 변경 대상은 0건이다.

검증에는 작성 완료·부분 작성·공백·미작성, 저장 후 상태 전환과 다시 수정, 학생 권한 경계, 백 개 이후 성장 기록의 출력, 분석 없는 수업, 개별·전체 학생 출력과 학생 간 기록 분리, 출력 조회 실패, 모델 정보의 기본 접힘과 학생 화면 숨김, 댓글 변경 범위·포인트·성장 기록 보존을 포함한다. 휴대전화 화면에서 발견한 질문 목록 정렬 버튼의 가로 넘침도 수정했다.

로컬 검증: 단위 테스트 3,604개와 커버리지 기준, 브라우저 회귀 44개, 타입 검사와 린트가 통과했다. 출력 문서를 화면 바깥에 독립 배치해 뒤에 빈 페이지가 붙는 문제를 수정했다. 동일한 시험 출력물은 내용 5쪽으로 생성되며 첫 질문부터 마지막 성장 기록까지 포함되는 것을 확인했다.
