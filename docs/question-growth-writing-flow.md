# 질문 작성 과정과 연결한 성장 기록

## 사용 흐름

- 질문하기의 첫 분석 문장을 수업별 초안에 보관한다. 질문을 수정하고 다시 분석해도 첫 문장을 유지한다.
- 최종 질문을 저장할 때 내용이 달라졌다면 질문 생성과 같은 트랜잭션에서 처음 질문과 고친 질문을 기록한다. 원문과 같은 질문은 변화 기록을 중복 생성하지 않는다.
- 저장 완료 화면에서 선택적으로 한 줄 돌아보기를 남긴다. 이 단계에서는 탐구 후 배운 점을 요구하지 않는다.
- 나의 질문의 성장 기록 이어쓰기에서 돌아보기와 탐구 후 배운 점을 각각 저장할 수 있다. 댓글이나 좋아요가 있어 질문 본문을 수정할 수 없는 경우에도 성장 기록은 이어 쓸 수 있다.
- 상세 리포트는 기록을 모아 보고 해당 질문의 이어쓰기 화면으로 이동한다. 담당 교사는 기존처럼 읽기만 가능하다.

## 자료와 권한

기존 성장 기록의 원문, 고친 질문, 배운 점과 버전은 유지한다. 한 줄 돌아보기만 빈 문자열 기본값의 새 필드로 추가한다. 기존 작성 요청도 계속 처리하여 배포 중 화면 버전이 달라도 호환된다.

새 화면은 실제로 수정한 필드만 전송한다. 다른 화면에서 기록을 수정하면 이전 버전의 저장을 거절하며 작성 중 입력은 보존한다. 명시적으로 다시 불러온 뒤 최신 버전으로 저장할 수 있다. 저장 실패와 저장 성공 후 재조회 실패를 구분한다.

질문 저장 포인트의 기존 지급 기준은 유지한다. 성장 기록 작성은 포인트를 추가 지급하지 않는다. 더미 자료를 재생성하지 않는다.

## 검증

- 전체 자동 검사 364개 파일, 3,583개 항목과 커버리지 기준 통과.
- 타입 검사, 정적 검사, 데이터베이스 스키마 및 접근 보안 검사, 운영용 빌드 통과.
- 브라우저 회귀 검사 38개 항목 통과: 질문 작성부터 돌아보기, 나의 질문의 이어쓰기, 날짜·교과·단원 필터, 언어 전환, 탐구설계 배포 상태.
- 휴대전화, 태블릿, 데스크톱 화면 및 밝은 테마와 어두운 테마 검증.
- 적용 전 비공개 백업과 적용 후 대조로 기존 더미 질문 190개 및 학습·포인트 자료 보존 확인.
- 실제 데이터베이스의 부분 저장 및 버전 충돌은 검증 트랜잭션에서 확인하고 전체 롤백하여 시험 기록을 남기지 않음.

교사 학생 연습 현황의 진단추천 문구는 별도 추천 요청이므로 이번 변경에 포함하지 않는다.
