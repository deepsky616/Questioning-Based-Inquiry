# 성장 기록 보호와 교사 수업 활용 개선

요청한 1, 2, 4, 5, 6번을 이 순서로 적용한다. 예시에서 수업 초안을 자동 생성하는 3번은 이번 변경에 포함하지 않는다.

## 1. 성장 기록 작성 내용 보호

- 성장 기록의 두 메모를 계정·질문별 브라우저 임시 초안으로 보관한다. 같은 브라우저에서 닫았다 열거나 새로고침하면 8시간 이내의 초안을 복원한다.
- 임시 보관 안내와 서버 저장 완료 안내를 구분한다. 교사가 조회하는 성장 기록은 학생이 저장한 서버 자료만 사용한다.
- 서버 조회와 작성 권한 확인 후 복원한다. 다른 계정의 초안을 복원하지 않으며 로그아웃·탈퇴 때 초안을 정리한다.
- 서버 버전이 바뀐 초안은 기존 충돌 안내로 연결한다. 학생이 명시적으로 다시 불러오기 전에는 덮어쓰지 않는다.
- 저장 실패에도 입력을 유지한다. 임시 보관이 실패하면 창을 닫을 때 확인하고, 저장 중에는 성장 기록 대화상자를 닫지 않는다.
- 저장 성공과 재조회가 확인된 초안만 정리한다. 늦은 저장 응답으로 다른 화면에서 작성한 새 초안을 지우지 않는다.
- 기존 처음 질문·고친 질문, 두 메모의 역할, 넓은 화면의 2×2 배열, 작은 화면의 한 열 배열을 유지한다.

## 2. 수업 활용 탭 정리

- 담당 학년 예시 중 교과를 선택할 수 있다. 담당 학년을 바꾸면 교과 선택을 초기화하여 빈 조합을 방지한다.
- 대표 예시를 먼저 표시하고 두 번째 예시는 ‘다른 예시 보기’로 펼친다. 교과를 선택하면 해당 예시만 바로 표시한다.
- 성취기준 원문과 학급 진단 이동은 유지한다. 진단 버튼은 접힌 예시 안에 넣지 않는다.

## 4. 진단 결과와 보충 연습 연결

- 선택한 질문 유형에 풀이 기록이 있어도 내장 연습 미리보기, 학생용 주소 복사, 문항 은행 관리를 제공한다.
- 현재 질문 유형을 미리보기와 학생용 주소에 반영한다. 기존 진단 기준·정답률·포인트 산식은 유지한다.

## 5. 교사의 분류 확인 이유와 이력

- 질문 분류 수정 창에 선택 항목인 ‘분류 확인·수정 이유’를 추가한다. 분류를 그대로 확인해도 첫 이력을 남길 수 있다.
- 수정 직전 분류, 교사가 확인한 분류, 실제 입력한 이유, 확인 교사와 시각을 기록한다. 과거 분류를 인공지능 원본이라고 추정하지 않는다.
- 담당 교사와 질문 작성 학생만 이력을 조회한다. 공개 질문을 읽는 다른 학생에게 확인 이유를 노출하지 않는다.
- 이력은 최신순으로 10개씩 조회한다. 해당 버튼을 펼칠 때만 서버에 요청한다.
- 질문 행을 잠근 동일 트랜잭션에서 분류와 이력을 저장한다. 이력 저장 실패는 분류 변경도 취소한다. 동일 교사의 같은 분류·이유 재전송은 중복 기록하지 않는다.
- 새 `question_classification_reviews` 테이블과 관계·인덱스만 추가한다. 기존 자료의 갱신·삭제·재생성이나 과거 이력 소급 생성은 하지 않는다. 직접 접근 권한 차단과 행 보안을 적용한다.
- 분류 수정 창의 작은 화면 스크롤, 입력란 이름 연결, 두 테마의 안내 색상도 함께 보완한다.

## 6. 전자칠판용 수업 화면

- 수업 활용 예시와 교사 질문 목록에서 ‘수업 화면으로 보기’를 제공한다.
- 목록에서는 현재 페이지의 질문 또는 그 페이지에서 선택한 질문을 큰 글씨로 표시한다. 화면을 연 뒤 배경 목록이 갱신되어도 발표 순서는 유지한다.
- 학생 이름과 분류·설명은 기본적으로 숨긴다. 교사가 버튼을 눌러 공개하며 다음 질문에서는 분류·설명을 다시 숨긴다.
- 이전·다음 버튼, 질문 영역에서의 방향키, 닫기와 탈출 키를 지원한다. 이름 공개 설정은 다시 열 때 초기화한다.
- 긴 질문 영역만 스크롤하고 조작 버튼을 화면 안에 유지한다. 한국어·영어 및 밝은·어두운 테마를 지원한다.
- 질문 내용, 공개 설정, 분석 결과, 포인트를 변경하지 않는다.

## 검증 근거

- 초안 복원·만료·계정 분리·저장 실패·버전 충돌, 분류 확인 권한·중복 방지, 예시 필터·접기, 진단 연결, 수업 화면 상태를 단위 검사한다.
- 브라우저 회귀 검사에 성장 기록 닫기·새로고침 복원, 저장 후 초안 정리, 교사 이유 입력과 이력 조회, 현재 페이지·선택 질문 발표를 추가한다.
- 실제 담당 5학년 자료를 읽어 한국어 밝은 375, 한국어 어두운 1440, 영어 밝은 768, 영어 어두운 375 화면에서 교과 필터·접기·성취기준·분류 공개·방향키·진단 이동·가로 넘침을 확인했다.
- 마이그레이션 전후 기존 질문·성장 기록·댓글·포인트 로그·연습·수업·학급 자료와 사용자 학급·포인트를 비교하여 동일함을 확인했다.
- 실제 데이터베이스에서 분류 변경과 이력 저장·중복 방지를 검사한 트랜잭션을 강제로 취소하고 원래 질문과 이력 수가 보존됨을 확인했다. 검증 이력을 영구 저장하지 않았다.
- 최종 단위 검사 375개 파일의 3,639개 검사, 타입 검사와 정적 검사를 통과했다. 전체 브라우저 회귀 검사 73개를 통과했다.
- 데이터베이스 검사를 포함한 운영 빌드와 배포 결과는 변경 요청의 검증 항목에 기록한다.
