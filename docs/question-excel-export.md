# 학생 질문 엑셀 다운로드

교사 페이지의 **질문탐구 → 전체 질문 목록 → 엑셀 다운로드**에서 사용한다.

## 사용 방법

1. 질문수업, 검색어, 질문 분류, 부적절 의심 필터와 정렬을 설정한다.
2. 필요한 질문만 저장하려면 목록의 체크 상자를 선택한다.
3. **엑셀 다운로드**를 누르고 범위를 선택한다.
   - **검색·필터 결과 전체**: 현재 조건에 맞는 모든 페이지의 질문.
   - **선택한 질문**: 현재 페이지에서 체크한 질문. 선택 항목이 있으면 기본값이다.
4. **다운로드**를 누르면 날짜와 시간이 붙은 `.xlsx` 파일을 받는다.

## 파일 내용

- **질문 목록**: 수업일·교과·주제, 저장된 학생 이름·학년·반·번호, 질문 원문과 분류, 한국시간 작성일시, 좋아요·댓글 수, 공개 상태, 질문·댓글의 부적절 의심 여부, 질문 의심 사유.
- **내보내기 정보**: 범위, 실제 질문 수, 내보낸 시각, 수업·검색·필터·정렬 조건.
- 학생 이름은 저장된 이름을 그대로 사용한다. 질문은 번역·요약 없이 원문을 사용한다.
- 첫 행을 고정하고 긴 질문은 셀 안에서 줄바꿈한다. 활동 수는 엑셀에서 계산할 수 있는 숫자 셀이다.
- 댓글 원문과 인공지능 답변은 포함하지 않는다.

## 구현과 확인 사항

- `POST /api/questions/export`는 인증된 교사에게만 제공한다.
- 목록 조회와 같은 교사 소속·담당 학급 범위, 검색, 필터, 정렬을 공유한다.
- 선택한 질문도 현재 필터와 권한을 다시 확인한다. 삭제되거나 범위를 벗어난 선택 항목이 있으면 새로 선택하도록 안내한다.
- 일반 목록의 30개 페이지 크기나 500개 조회 상한을 다운로드에 적용하지 않는다.
- 한 번에 최대 10,000개를 제공한다. 초과 시 일부를 자르지 않고 범위를 좁히도록 안내한다.
- 파일은 서버 메모리에서 생성하며 응답을 캐시하지 않는다. 수식 모양 문자열도 텍스트 셀로 기록한다.
- 내려받기 실패 시 창에 안내를 표시하고 재시도할 수 있다.
- 실제 파일 재읽기 검증과 휴대전화·컴퓨터 화면 다운로드 시험을 자동 검사에 포함한다.
