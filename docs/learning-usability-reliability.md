# 학습 사용성 및 안정성 개선

## 반영 범위

- 댓글 조회 실패와 빈 목록을 구분하고 재시도 제공. 등록 실패 시 입력 유지, 조회 중 중복 조작 방지.
- 탐구설계 참고 자료 조회 및 영어 번역 실패 안내. 원문과 질문 작성을 유지하면서 다시 시도.
- 좋아요 실패 안내와 주요 조작의 터치 영역 및 어두운 테마 대비 보완.
- 교사 탐구질문 수업 만들기 초안을 계정별 브라우저 저장소에 최대 7일 보관. 복구 여부 선택, 단계·교과·영역·성취기준·작성 문장·배포 설정 복원. 저장 완료 후 초안 제거. 설계 저장 후 수업 생성이 실패한 경우 재시도에 기존 설계를 재사용.
- 휴대전화·태블릿에서 선택한 수업 요약과 수업 변경 버튼 제공. 목록을 접어 입력창에 빨리 접근하고 데스크톱 목록은 유지.
- 원문과 동일한 쉬운 설명 및 중복 안내를 숨김. 더미 5학년 수업 8개의 설명을 실제 질문에 맞는 생활 언어로 수정.
- 연습 진단에서 표본 부족과 집중 연습 추천을 구분하고 추가로 필요한 문항 수 표시.
- 교사 학생 관리에서 참여 확인 사유를 질문 기록과 미작성 수업 수로 표시.
- 상세 리포트에 질문 성장 기록 추가. 학생은 자신의 처음 질문·고친 질문·배운 점을 저장하고 담당 교사는 읽기만 가능. 처음 질문은 서버 원문으로 보관하며 동시 수정 시 버전 충돌을 안내하고 입력 보존. 최근 질문·기록 각각 최대 100개 조회.
- 더미 리포트와 질문놀이 학습 현황에 현재 날짜/최근 기록이 있는 기간 선택 추가. 인쇄 시 조회 기준 반영. 실제 활동 날짜·포인트·누적 합계는 변경하지 않음.

## 데이터 보호

성장 기록은 별도 테이블 `question_growth`에 저장한다. 서버에서 계정 및 담당 학급을 검사하고, 데이터베이스의 행 접근 정책과 외부 직접 접근 차단을 적용한다. 원 질문을 삭제하면 해당 질문의 성장 기록도 함께 삭제된다.

더미 설명 갱신은 `scripts/refresh-demo-student-guides.mjs`로 수행한다. 더미 교사와 수업 원문을 확인하고 비공개 백업을 만든 뒤 트랜잭션 적용·복원 검증 후 반영했다. 학생이 공유한 질문과 원래 출처·정렬·통합 정보는 보존한다. 기존 질문·댓글·좋아요·연습·게임·포인트 및 기록 날짜가 동일함을 대조했다. 전체 더미 재생성은 수행하지 않았다.

## 확인 결과

- 타입 검사, 코드 규칙 검사, 운영용 빌드, 데이터베이스 마이그레이션·스키마 차이·구조·접근 권한 검사 통과.
- 자동 검사 363개 파일, 3,574개 검사 통과. 로직과 서버 경로의 커버리지 기준 통과.
- 필터 연동, 전체 조건 복귀, 탐구설계 배포 상태, 언어 전환, 화면 및 테마 브라우저 검사 34개 통과.
- 실제 교사·학생 계정으로 성장 기록 저장·교사 조회·교사 쓰기 차단·실패 시 입력 보존 확인. 확인용 성장 기록은 검사 후 제거.
- 교사 초안 1단계와 3단계의 새로고침 복구 확인. 교과·영역·성취기준·핵심 문장 유지.
- 시연 기간 변경 전후 학생·학급 리포트 및 질문놀이 누적 합계 동일 확인.
- 375/768/1440픽셀 밝은·어두운 화면, 영어 화면과 실제 터치 환경의 주요 6개 화면 확인. 확인한 화면에서 가로 넘침과 실행 오류 없음.
- 로컬 시험용 로그인 설정은 복원하고 임시 실행 파일 삭제. 원래 교사·학생 로그인 시작 파일 보존.

초안은 현재 브라우저에 저장되므로 다른 기기로 자동 동기화되지 않는다. 네트워크와 외부 번역 서비스 실패 가능성은 남으며, 실패를 안내하고 재시도할 수 있도록 처리했다.
