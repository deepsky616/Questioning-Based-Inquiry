# 최근 기능과 연결한 교사·학생 시연 자료

김탐구 선생님과 김질문 학생의 기존 5학년 1반 자료에 질문 작성, 성장 기록, 교사 확인, 연습 진단과 상세 리포트를 연결하는 추가 사례를 구성한다. 2026년 9월 11일 기준 자료이며 학습 내용은 기존에 확인한 5학년 성취기준과 안내 자료를 재사용한다.

## 추가 구성

| 영역 | 구성 |
| --- | --- |
| 질문수업 | 최근 평일의 국어·수학·과학·사회 수업 4개와 기준일의 간단 과학 질문수업 1개 |
| 탐구설계 | 5학년 성취기준·용어·탐구 안내가 연결된 설계 4개. 3개 수업은 질문 배포 완료, 사회 수업은 배포 전 |
| 질문 | 학생 질문 41개, 배포한 교사 질문 15개. 학급별 참여 인원과 공개 여부를 다르게 구성 |
| 성장 기록 | 새 기록 19개: 두 메모 완료 12개, 작성 중 6개, 질문만 저장 1개 |
| 김질문 성장 사례 | 새 질문 8개 중 완료 4개, 작성 중 2개, 메모 작성 전 1개, 성장 기록을 아직 열지 않은 질문 1개 |
| 교사 확인 | 새 김질문 질문 4개에 유형을 확인한 이유를 구체적으로 기록. 기존 질문의 과거 확인 이력은 추정하지 않음 |
| 상호작용 | 서로 다른 댓글 40개와 좋아요 104개. 자기 글이나 비공개 질문에는 상호작용을 추가하지 않음 |
| 교사 문항 | 분류 6개, 바꾸기 3개, 만들기 3개. 담당 학생의 연습 문항에도 연결 |
| 연습 사례 | 12명에게 서로 다른 횟수·성공률의 128개 풀이 기록 추가. 나머지 학생의 기존 활동량과 차이를 유지 |

국어는 조사 대상과 근거의 타당성, 수학은 평균과 개별 자료의 관계, 과학은 단열과 공정한 비교, 사회는 유적·유물의 관찰과 추론을 다룬다. 학생의 성장 메모는 실제 연결된 질문 내용에 맞추며, 수행하지 않은 실험의 구체적인 측정 결과를 만들어 넣지 않는다.

사용자가 함께 수정하도록 지정한 기존 성장 기록 2개는 처음 질문과 고친 질문을 유지하고, 두 메모만 구체화한다. 수정 전 문장과 버전이 예상과 다르면 적용을 중단하여 작업 중 새로 작성한 내용을 덮어쓰지 않는다. 수정 버전은 각각 1 증가한다.

## 진단 연결 수정

교사 문항의 유형은 교사 연습 현황에 반영되지만 학생의 `/api/practice/progress`에서는 조회하지 않아, 같은 풀이가 학생 화면의 유형별 진단에서 누락됐다. 학생 본인의 최근 100회 풀이에서 사용한 교사 문항만 조회하고 분류 유형·바꾸기 목표를 진단에 전달한다. 정답이나 문항 내용은 응답에 추가하지 않는다. 삭제된 문항과 목표 유형을 저장하지 않는 질문 만들기는 기존 집계 정책을 유지한다.

## 적용과 보존

- 내용·계획은 `scripts/demo-feature-learning-content.mjs`, 실행은 `scripts/enrich-demo-feature-learning.mjs`에서 관리한다.
- 기본 실행은 변경 전 미리보기다. `--rehearse --backup=절대경로`는 트랜잭션 전체 적용·검증 후 롤백하고 원본을 대조한다. `--apply --backup=다른절대경로`로 실제 적용한다.
- 백업은 새 파일에 소유자 전용 권한으로 저장한다. 비밀번호, 인공지능 키, 자동 로그인 실행 표는 백업과 로그에 넣지 않는다.
- 지정된 시연 교사와 28명의 학교·담당 학급·역할을 검사하고, 작업 전후 자료를 대조한다. 같은 버전의 추가 자료가 이미 있으면 중복 실행을 거절한다.
- 지정된 두 성장 메모와 추가 연습에 따른 학생 총점 외의 기존 자료는 갱신하지 않는다. 기존 수업, 질문, 댓글, 좋아요, 분석, 놀이 기록과 포인트 지급 내역을 보존한다.
- 연습 성공에만 기존 정책의 점수를 추가한다. 같은 문항·유형의 하루 중복 지급을 방지하고 기존 지급분을 포함한 하루 15점 상한을 적용한다. 원본 질문·댓글 예시는 보충 자료로 추가하며 포인트를 소급 지급하지 않는다.
- 외래키·중복 제한·포인트 보호 규칙을 유지한 하나의 트랜잭션으로 반영한다. 스키마 변경과 전체 시연 초기화는 수행하지 않는다.
- 기존 분석 결과는 보존한다. 새 수업의 인공지능 분석은 실제 분석 기능으로 생성하고 서버에 저장된 모델 정보만 사용한다.

## 검증

계정 범위·중복 실행·동시 수정 보호, 새 자료의 연결, 날짜와 상태, 원문 보존, 댓글 다양성, 문항 형식, 유형별 진단, 포인트 정책을 자동 검사한다. 실제 데이터베이스에서는 전체 적용 후 원본 복원 검증을 진행하고, 적용 후 두 시연 계정의 질문 목록·성장 기록·교사 문항·진단·상세 리포트와 인쇄 자료를 확인한다.
