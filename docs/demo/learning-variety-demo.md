# 5학년 시연 학습 기록 다양화

기존 자료는 모든 학생이 혼자·인공지능·친구 놀이를 한 번씩 하고, 네 가지 놀이를 같은 학생 수로 순환 배정했다. 답변은 대부분 4개, 좋아요는 6개였다. 기존 기록을 보존하면서 학생별 활동 선호도와 참여 정도가 다른 예시를 추가한다.

- 일곱 질문놀이의 참여 학생 수·완료 횟수·인정 활동 수를 다르게 구성한다. 최근 활동은 평일에 배치하고 참여가 잦은 학생과 최근 활동이 없는 학생을 함께 둔다.
- 친구 놀이에는 같은 방·놀이·완료 시각을 공유하는 3~6명의 모둠을 구성한다. 학생별 인정 수는 놀이 상한을 넘지 않는다.
- 연습은 실제 문항 은행에 연결한다. 학생별 시도 수·성공 비율·질문 유형을 다르게 하고 오답 후 성공한 기록도 포함한다. 오답에는 점수를 지급하지 않는다.
- 수업의 성취기준과 5학년 질문 은행에 맞는 질문·답변을 보충하고 좋아요 분포도 다르게 구성한다. 질문과 답변 예시는 추가 활동 자료이며 기존 질문·답변 지급 기록을 다시 계산하지 않는다.
- 기존 포인트 기록은 그대로 보존한다. 새 놀이·연습에 해당하는 점수만 현재 정책과 하루 상한에 맞춰 추가하고 학생 총점은 지급 기록 합계와 맞춘다. 시연 친구 놀이에 빠졌던 완료 표시는 추가 점수 없이 보완한다.
- 최근 14일 그래프는 데이터베이스에 저장된 세계 표준시를 한국 시간으로 변환한 뒤 날짜별로 집계한다. 오전 기록이 전날로 이동하던 오류를 수정한다.
- 이전 형식의 혼자·인공지능 포인트가 완료 실행에도 연결된 경우, 교사 통계가 이를 친구 놀이로 중복 집계하지 않도록 수정한다.

자료 구성은 `scripts/demo-learning-variety.mjs`, 운영 반영은 `scripts/enrich-usb-demo-learning.mjs`에서 관리한다. 다음 명령은 5학년 시연 자료 전환을 마친 후 사용한다. 전체 시연 초기화 명령을 실행하지 않는다.

```sh
node scripts/enrich-usb-demo-learning.mjs
node scripts/enrich-usb-demo-learning.mjs --rehearse --backup=비공개백업경로
node scripts/enrich-usb-demo-learning.mjs --apply --backup=다른비공개백업경로
```

첫 명령은 미리보기다. `--rehearse`는 전체 적용·검증·롤백·원본 대조를 수행한다. `--apply`는 검증한 변경을 커밋한다. 적용 전 지정한 28명 모두의 학교·학년·반·더미 계정 여부와 기존 지급 합계를 확인한다. 같은 버전의 기록이 이미 있으면 중복 적용을 거절한다. 비공개 백업 파일은 새 경로로 만들고 권한을 소유자만 읽고 쓸 수 있게 제한한다.

실제 반영은 하나의 트랜잭션에서 수행한다. 기존 질문·답변·포인트·활동·연결과 시연 밖의 계정을 수정하지 않는다. 사용자 총점과 분석의 활동 개수만 추가한 기록에 맞추고 변경 전후 자료를 대조한다. 보호 규칙이나 데이터베이스 스키마를 변경하지 않는다. 일부 실패 시 전체 변경을 롤백한다.
