# 5학년 교사·학생 연결 시연

김탐구 선생님과 김질문 학생은 질문초등학교 5학년 1반에 연결된다. 김질문은 기존 1번 계정을 사용하며 같은 반 28명과 순위 비교용 더미 학생의 계정 식별자, 포인트, 좋아요와 댓글 연결을 유지한다.

시작 파일에는 교사 로그인과 학생 로그인 버튼을 제공한다. 실행 표는 기존 값을 사용하고 주소 조각으로만 전달한다. 서버는 유효 기간과 실행 권한을 확인한 뒤 고정된 더미 계정만 조회한다. 로그인 후 세션의 계정·역할·시연 여부가 맞는지 확인하고 대시보드로 이동한다. 역할 없는 이전 링크는 학생 로그인을 유지한다. 학년 전환 배포와 데이터 적용 사이의 호환성을 위해 지정된 시연 계정에 한해 4학년과 5학년 자료를 모두 인증할 수 있다.

계정 삭제, 학생 추가·삭제·비밀번호 초기화, 인공지능 설정 변경은 시연 연결을 유지하기 위해 제한한다. 일반 교사 계정의 기존 기능은 유지한다. 시연 인공지능 사용 가능 여부는 기존 시연 설정에서 확인하며 실제 키를 시작 파일이나 응답에 넣지 않는다.

## 기존 자료 적용

`scripts/migrate-usb-demo-grade-five.mjs`는 전체 시연 초기화 명령과 별개다. 기본 실행은 변경 계획만 확인한다. `--apply --backup=비공개백업경로`를 지정하면 백업한 뒤 하나의 트랜잭션 안에서 지정된 계정과 기존 수업·질문·답변의 학년과 내용을 갱신한다. 계정 신원, 수업 연결, 목록이 예상과 다르면 변경하지 않는다. 이후 원래 데이터와 대조해 포인트, 좋아요, 댓글 대상 등 허용하지 않은 값이 달라지면 전체 변경을 취소한다.

운영 반영 순서: 인증 코드 배포 완료 확인 → 자료 전환 적용 → 기존 시작 파일의 실행 표를 유지하며 화면 갱신 → 교사·학생 계정 전환 및 5학년 수업 연결 확인.

기존 자료를 전환할 때 `demo:seed`를 실행하지 않는다. 시작 파일을 갱신할 때 전체 제출 폴더를 재생성하지 않고 `createDemoLauncherHtml`로 지정 파일만 갱신한다. 실행 표와 데이터 백업은 저장소에 포함하지 않는다. 질문·답변 번역은 원문 해시가 달라져 변경한 내용에 맞게 다시 생성된다.
