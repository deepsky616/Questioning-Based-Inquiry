# 의미 없는 입력의 분류와 저장 방지

## 동작

- 질문하기의 분석, 새 질문 저장, 기존 질문 내용·유형 수정, 질문 만들기·바꾸기 연습은 공통 내용 검사를 통과해야 한다.
- 웃음 표시·자음만 있는 글, 기호·이모지만 있는 글, 짧은 글자 단위의 명백한 반복은 `400 / UNCLASSIFIABLE_QUESTION`과 재작성 안내를 반환한다.
- 이 경우 인공지능 호출, 정상 질문 유형 부여, 질문 저장, 포인트 지급이 발생하지 않는다.
- `왜요?`, `주황색인가요?`, `1+1?` 및 의미 있는 문장 안의 웃음 표시는 허용한다. 이 검사는 모든 비문이나 무관한 문장을 판별하는 의미 분석기가 아니다.
- 학생이 분석 후 내용을 바꾸면 기존 분석으로 저장하지 못하는 기존 검증도 유지한다.

## 기존 검토 자료

- 의미 없는 검토 사례는 두 유형 모두 `unclassified`, 점수·탐구 유형은 비워서 보관한다.
- 목록은 ‘분류 불가’를 하나만 표시한다. 교사는 재작성 안내 댓글과 부적절 의심 확인을 할 수 있다.
- 정상 유형 통계와 탐구 그래프에서 제외한다. 수업 분석에도 정상 유형을 붙이지 않는다.
- 이번 자료 정정은 시연 질문 `usb-demo-moderation-v1-question-03` 한 건에만 적용했다. 실제 학생의 과거 자료와 기존 포인트는 일괄 변경하지 않았다.

## 데이터베이스 적용 및 복구

- `20260916023000_allow_unclassified_questions`는 기존 유형을 유지하면서 분류 불가 상태를 추가한다. 데이터 변경은 포함하지 않는다.
- 두 유형 중 하나만 분류 불가이거나, 분류 불가 상태에 분류 점수·탐구 유형을 붙이는 것은 데이터베이스에서 거절한다.
- 적용 전 전체 질문 1,224행의 임시 복사본에 변경을 적용했다. 기존 유형 보존, 분류 불가 저장, 잘못된 조합 네 가지의 거절을 확인하고 복사본을 폐기했다.
- 시연 자료 변경 전 별도 비공개 백업을 만들었으며, 변경 후 학생 총점이 동일함을 확인했다.
- 앱을 되돌릴 경우 확장된 제약은 유지할 수 있다. 제약까지 축소해야 한다면 먼저 분류 불가 자료를 백업하고 개별 검토하여 처리한 뒤, 기존 유형 제약을 복원하는 새 마이그레이션을 추가한다. 의미 없는 글에 정상 유형을 자동 배정하지 않는다.
