# 시연 학급 내용 갱신

## 구성

김탐구 교사와 김질문 학생이 속한 5학년 1반의 시연 자료를 대상으로 한다.

- 평균 수업은 5학년 2학기 과학 `날씨와 우리 생활`로 바꾼다.
- 다각형 넓이 수업은 5학년 1학기 과학 `빛의 성질`로 바꾼다.
- 수업, 탐구설계, 학생 안내, 질문, 답변, 성장 기록, 교사 검토 사유, 교사 연습 문항과 연결된 놀이 기록을 함께 갱신한다.
- 기존 식별자는 학습 기록과 포인트 연결을 유지하기 위해 보존한다. 내부 식별자의 `math`, `average`는 이전 수업에서 사용한 이름이다.

학년과 성취기준 연결은 [경기도교육청 2026학년도 5~6학년 수업·평가 계획](https://www.goe.go.kr/resource/goe/na/bbs_2675/2026/02/116dc7a4-254a-44fe-9e77-3e908ecc5ff3.pdf)과 저장소의 교육과정 자료를 따른다.

## 질문과 답변의 다양성

`demo-question-variants.json`은 기본 질문에 연결된 상황별 질문, 예상 답변, 탐구 안내, 친구 답변의 정적 자료다. 자료 생성 명령을 실행할 때마다 외부 AI를 호출하지 않는다.

`demo-question-variety.mjs`는 공백과 문장부호를 정리한 내용으로 중복을 검사한다. 같은 교실의 다른 학생에게도 동일한 질문이나 답변을 다시 배정하지 않는다. 준비한 문장이 부족하면 생성을 중단한다. 단순한 앞말 추가로 문항 수를 늘리지 않는다. 답변은 선택된 질문에 연결된 자료에서 고른다.

교사가 학생 질문을 수업 탐구 질문으로 채택한 경우에는 원문을 참조할 수 있다. 이 인용은 학생끼리 같은 문장을 반복 생성하는 경우와 구분한다.

## 교사 검토 시연

`demo-moderation-content.mjs`에 다섯 가지 합성 사례를 둔다.

1. 친구 비하
2. 다른 사람의 개인정보 공개 유도
3. 의미 없는 문자 반복
4. 수업과 무관한 거래 유도
5. 답 베끼기와 포인트 악용 유도

실제 개인정보는 포함하지 않는다. 질문은 다섯 명의 더미 학생에게 나누어 연결하고 비공개로 저장한다. 의심 사유에는 `시연용`과 `교사 확인 필요`를 표시한다. 포인트, 댓글, 좋아요는 생성하지 않는다.

김탐구 교사로 로그인한 뒤 **질문탐구 → 전체 질문 목록 → 부적절 의심만**에서 확인한다. 해당 목록이 조회하는, 배포 질문이 없는 `빛의 성질` 직접 탐구 수업에 연결한다. 교사는 기존 `이상없음` 기능으로 검토를 연습할 수 있다. 검토한 기록의 표시를 갱신 명령이 다시 강제로 켜지지 않도록 한다.

## 기존 운영 시연 자료 갱신

미리보기:

```sh
npm run demo:refresh-content -- --env-root=/절대/환경설정/경로
```

적용에는 변경 후 질문과 답변을 바탕으로 실제 생성한 분석 결과가 필요하다. 분석 입력과 갱신 계획의 해시가 같아야 한다. 분석 파일의 구조는 다음과 같다.

```json
{
  "sourceDigest": "scienceAnalysisDigest의 결과",
  "results": {
    "기존 분석 식별자": {
      "summary": "실제 생성 결과",
      "analysisModel": "실제 사용 모델",
      "analyzedAt": "생성 시각"
    }
  }
}
```

나머지 분석 항목도 기존 학생별·학급별 분석 형식에 맞게 포함한다. 운영 갱신 전에 전체 적용 후 되돌리는 모의 검사를 실행한다.

```sh
npm run demo:refresh-content -- --env-root=/절대/환경설정/경로 --rehearse --analysis=/비공개/분석.json --backup=/비공개/모의검사백업.json
npm run demo:refresh-content -- --env-root=/절대/환경설정/경로 --apply --analysis=/비공개/분석.json --backup=/비공개/적용백업.json
```

백업 파일은 새 파일에만 쓰고 읽기 권한을 소유자로 제한한다. 전체 적용은 하나의 트랜잭션에서 수행한다. 지급된 질문·댓글 내용과 연결된 중복 방지 키를 함께 갱신하고 지급액은 유지한다. 작업 중 자료가 달라졌거나 검증에 실패하면 되돌린다. 포인트 보호 규칙도 트랜잭션 안에서 복원 여부를 검사한다.

검사 대상은 더미 계정의 신원과 담당 학급, 원래 기록의 수와 연결, 총점과 지급 내역, 질문·답변 중복, 의심 사례 수, 분석 입력의 일치 여부다. 일반 교사와 실제 학생 자료가 섞이면 적용하지 않는다.
