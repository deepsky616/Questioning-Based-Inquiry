# 질문학습 웹 슬라이드와 연습 요약 설계

## 배경

제공된 `사실, 개념, 논쟁적 질문.pptx`는 19장으로 질문의 중요성, 열린 질문과 닫힌 질문, 탐구, 사실적·개념적·논쟁적 질문, 유형 비교와 탐구 단계를 설명한다. `사실적-개념적-논쟁적 질문를 만드는 방법.docx`는 세 유형의 정의와 유형마다 세 가지 질문 만들기 공식 및 예시를 보완한다.

원본을 그대로 웹에 옮기면 제목만 있는 장과 반복 설명이 남고, 문서 내용을 한 장에 더하면 글이 과밀해진다. 학생과 교사가 수업이나 자기 학습에 함께 쓸 수 있도록 한 장에 학습 목표 하나만 담는 웹 슬라이드로 재구성한다.

## 목표

1. 학생과 교사 메뉴에서 대시보드 바로 오른쪽에 `질문학습`을 추가한다.
2. 학생과 교사는 같은 전체 질문학습 슬라이드를 각 역할 경로에서 본다.
3. 학생과 교사의 질문연습에는 전체 슬라이드가 아니라 짧은 유형 요약과 역할에 맞는 자세히 보기 링크만 둔다.
4. 열린·닫힌 질문과 사실적·개념적·논쟁적 질문이 서로 다른 분류 기준임을 명확하게 가르친다.
5. 긴 글 목록이 아니라 개념, 비교, 예시, 짧은 확인 문제로 이어지는 반응형 슬라이드 경험을 제공한다.
6. 학습 이력과 포인트를 저장하지 않고 기존 데이터베이스와 사용자 자료를 바꾸지 않는다.

## 메뉴와 경로

학생 메뉴 순서는 다음과 같다.

```text
대시보드 -> 질문학습 -> 질문연습 -> 질문하기 -> 질문탐구 -> 질문놀이 -> 설정
```

학생 질문학습 경로는 `/student-question-learning`이다.

교사 메뉴 순서는 다음과 같다.

```text
대시보드 -> 질문학습 -> 질문연습 -> 탐구질문 -> 수업세션 -> 질문조회 -> 질문놀이 -> 학생관리 -> 설정
```

교사 질문학습 경로는 `/teacher-question-learning`이다.

상단 `AppNav`와 본문 아래 `PageNav`는 각 역할의 같은 배열을 사용한다. 따라서 큰 화면, 더보기 메뉴, 작은 화면 메뉴, 문서 순서와 이전·다음 이동 순서가 함께 바뀐다.

## 구성요소 경계

### 공통 학습 자료

`src/lib/question-detective-content.ts`가 다음 자료의 단일 원본이 된다.

- 열린 질문과 닫힌 질문의 정의와 같은 주제 예시
- 사실적·개념적·논쟁적 질문의 짧은 소개와 학생 눈높이 정의. 사실적 질문은 자료에 적힌 답뿐 아니라 기억, 관찰, 조사, 계산 또는 정해진 절차로 확인할 수 있는 정보까지 포함한다.
- 각 유형의 질문 만들기 공식 세 개와 공식별 예시
- 같은 환경 주제로 만든 세 유형 비교
- 사실 수집, 관계 찾기, 근거 있는 의견 만들기 단계
- 즉석 확인 문제와 정답 설명

질문학습 슬라이드와 질문연습 요약은 이 자료를 함께 읽는다. 화면마다 정의나 예시를 복사해 따로 관리하지 않는다.

원본 학습 본문과 예시는 한국어 고정 자료로 유지한다. 메뉴, 페이지 제목, 이동 단추와 접근성 이름은 기존 한국어·영어 번역 체계를 사용한다.

### 전체 슬라이드

`src/components/shared/QuestionDetectiveSlides.tsx`는 전체 슬라이드 표시와 이동만 담당한다. 학생·교사 경로나 연습 상태를 알지 않는다.

`src/components/shared/QuestionLearningExperience.tsx`는 페이지 제목과 전체 슬라이드를 조합한다. 학생과 교사 경로의 `page.tsx`는 이 공통 경험을 그대로 사용한다.

### 질문연습 요약

`src/components/shared/QuestionLearningSummary.tsx`는 짧은 요약만 표시하고 `detailsHref`를 입력으로 받는다.

- 학생 질문연습은 `/student-question-learning` 링크를 넘긴다.
- 교사 질문연습의 직접 해보기 탭은 `/teacher-question-learning` 링크를 넘긴다.
- 요약은 열린·닫힌 질문의 한 줄 차이, 세 사고 유형의 한 줄 소개와 유형별 대표 예시 한 개씩만 보여준다.
- `왜`, `어떻게` 같은 질문 낱말은 단서일 뿐이며, 답할 때 필요한 사고가 분류 기준이라는 안내를 함께 둔다.
- 긴 정의, 아홉 가지 공식, 전체 비교표, 탐구 단계와 확인 문제는 넣지 않는다.

`src/components/shared/QuestionPracticeView.tsx`는 분류, 질문 바꾸기와 질문 만들기 연습만 담당한다. 질문학습 슬라이드나 역할별 경로를 직접 가져오지 않는다.

## 슬라이드 흐름

전체 학습은 14장으로 구성한다.

1. **질문 탐정단**: 탐구의 열쇠를 찾는 학습 목표를 소개한다.
2. **답을 찾는 시대에도 질문은 사람이 정한다**: 인공지능 시대의 질문 중요성을 학생 언어로 설명한다.
3. **질문에는 두 개의 분류 기준이 있다**: 답의 범위와 생각의 목적을 먼저 구분한다.
4. **닫힌 질문은 확인하고 열린 질문은 생각을 넓힌다**: 같은 주제의 두 질문을 나란히 비교한다.
5. **탐구는 사실에서 관계와 판단으로 깊어진다**: 세 질문 유형을 하나의 학습 여정으로 연결한다.
6. **사실적 질문은 확인 가능한 정보를 정확하게 찾는다**: 기억, 관찰, 조사, 계산 또는 정해진 절차로 답할 수 있는 질문임을 명확한 예시와 함께 보여준다.
7. **사실적 질문은 대상, 때와 곳, 수량과 방법을 묻는다**: 세 공식과 대표 예시를 단계적으로 보여준다.
8. **개념적 질문은 사실을 연결해 원리를 찾는다**: 이유, 관계와 영향의 의미를 보여준다.
9. **개념적 질문은 이유, 비교, 의미와 영향을 묻는다**: 세 공식과 대표 예시를 단계적으로 보여준다.
10. **논쟁적 질문은 가치가 충돌하는 선택을 근거로 판단한다**: 단순한 취향 질문과 구분한다.
11. **논쟁적 질문은 선택, 공정함, 책임과 대안을 묻는다**: 세 공식과 대표 예시를 단계적으로 보여준다.
12. **같은 환경 주제도 세 깊이로 물을 수 있다**: 사실적·개념적·논쟁적 질문을 한눈에 비교한다.
13. **어떤 질문인지 직접 찾아보자**: 저장하지 않는 세 문항 즉석 확인과 설명을 제공한다.
14. **사실을 모으고 연결한 뒤 근거 있는 의견을 만든다**: 세 단계를 종합하고 질문연습으로 이어준다.

각 장은 하나의 핵심 주장만 갖는다. 원본의 제목 전용 장은 다음 내용 장과 합치고, 문서의 긴 정의와 공식은 유형별 두 장으로 나눈다.

## 내용 수정과 보완

다음 문제는 웹 자료에서 바로잡는다.

- 문서 제목의 `질문를`을 `질문을`로 고친다.
- 열린·닫힌 질문은 `답의 범위`, 세 사고 유형은 `생각의 목적과 깊이`라는 별도 축으로 설명한다.
- `왜`가 들어간 질문을 무조건 열린 질문이나 개념적 질문으로 분류하지 않는다. 자료에 이유가 직접 제시돼 단순 확인만 요구하는지 함께 본다.
- `어떻게` 질문도 낱말만으로 분류하지 않는다. 방법이 자료에 직접 제시되거나 관찰, 조사 또는 정해진 절차로 확인할 수 있으면 사실적 질문이 될 수 있고, 원리나 관계를 설명해야 하면 개념적 질문이 된다.
- 질문 낱말은 유형을 찾는 단서일 뿐이며, 실제 기준은 답할 때 필요한 사고와 근거임을 모든 유형 설명에 일관되게 적용한다.
- 닫힌 질문의 모호한 이유 예시는 답이 자료에 직접 있는지 분명한 예시로 교체한다.
- 석굴암이 있는 산의 이름을 묻는 예시는 `어디인가요`가 아니라 `무엇인가요`로 고친다.
- `생각의 전쟁터`는 `근거를 나누는 토론 질문`으로 바꿔 협력적인 학습 어조를 사용한다.
- 미래 리터러시 설명은 `인공지능이 답을 빠르게 찾는 시대일수록 무엇을 물을지 정하는 힘이 중요하다`는 학생 눈높이 문장으로 줄인다.
- 논쟁적 질문은 단순 선호가 아니라 둘 이상의 가치, 선택 또는 책임이 있고 근거로 판단할 수 있어야 한다.

## 화면과 상호작용

- 첫 화면부터 실제 슬라이드 무대를 보여주고 별도 소개용 방문 화면을 만들지 않는다.
- 슬라이드 무대는 큰 화면에서 안정적인 16:9 비율을 유지하고, 작은 화면에서는 내용 높이에 맞게 늘어나 글이 잘리지 않게 한다.
- 유형 색은 사실적 질문에 하늘색, 개념적 질문에 초록, 논쟁적 질문에 장미색을 사용한다. 연두와 보라는 원본 자료를 떠올리는 작은 강조색으로만 쓴다.
- 표지에는 학생들이 질문 단서를 찾는 모습을 담은 새 비트맵 삽화를 사용한다. 원본 PPT의 교수 인터뷰 화면은 작은 글자가 읽히지 않고 학생 학습 맥락과 맞지 않아 재사용하지 않는다.
- 본문 장은 Lucide의 검색, 연결, 저울과 전구 아이콘 및 간단한 흐름 시각화를 사용한다. 같은 카드 격자를 모든 장에서 반복하지 않고 장의 핵심 주장에 맞춰 비교, 단계와 예시 구성을 달리한다.
- 버튼은 Lucide 이전·다음 아이콘과 글자를 함께 사용하고 최소 44픽셀 누름 영역을 제공한다.
- 이전, 다음, 처음, 끝 키를 지원한다. 활성 진행 항목만 키보드 초점을 받고 나머지는 `tabIndex=-1`을 사용한다.
- 슬라이드 본문은 `tabpanel`로 표시하고 현재 장 번호는 `aria-live="polite"`로 알린다.
- 진행 표시를 누르면 해당 장으로 이동한다. 작은 화면에서는 모든 작은 점을 한 줄에 강제로 넣지 않고 현재 구간 중심의 간단한 진행 표시를 사용한다.
- 비교 자료는 큰 화면에서 표, 작은 화면에서 세로 목록으로 바꿔 가로 넘침을 막는다.
- 움직임 감소 설정을 존중하며 전환 효과가 없어도 모든 내용을 사용할 수 있다.
- 즉석 확인 문제는 현재 화면 안에서만 채점하고 새로 고침 뒤에는 초기화한다. 포인트 API와 데이터베이스를 호출하지 않는다.

## 자료 영향

Prisma 스키마, 마이그레이션과 API는 바꾸지 않는다. 질문학습 완료 여부, 슬라이드 위치, 확인 문제 결과와 포인트를 저장하지 않는다.

기존 질문, 포인트, 연습 기록과 교사 자료에는 차이가 없다. 추가되는 것은 정적 학습 자료, 공통 화면 구성요소, 역할별 경로와 메뉴 번역뿐이다.

## 현재 작업 초안 처리

현재 작업 폴더에는 전체 슬라이드를 공용 `QuestionPracticeView` 안에 넣는 미완성 변경이 있다. 이를 되돌려 버리지 않고 다음처럼 목표 구조에 맞춰 사용한다.

- 새 `QuestionDetectiveSlides` 초안은 전체 질문학습 화면의 출발점으로 사용한다.
- 공용 연습 보기에서 전체 슬라이드 직접 가져오기를 제거한다.
- 학생과 교사의 연습 페이지가 공통 요약을 각 역할의 자세히 보기 링크와 함께 조합한다.
- 전체 슬라이드 결합을 고정한 기존 초안 시험은 역할 분리와 공통 자료 재사용을 검증하는 시험으로 바꾼다.
- 다른 작업자가 만든 정의, 공식과 예시 개선은 내용이 원본 자료와 맞는지 확인한 뒤 보존한다.

## 시험 설계

1. 공통 자료에 세 질문 유형과 유형별 공식 세 개가 모두 있다.
2. 사실적 질문 정의가 기억, 관찰, 조사, 계산과 정해진 절차로 확인 가능한 정보를 포함하며, `왜`와 `어떻게` 같은 낱말만으로 유형을 정하지 않는다.
3. 학생 메뉴 전체 순서는 정확히 `대시보드, 질문학습, 질문연습, 질문하기, 질문탐구, 질문놀이, 설정`이다.
4. 교사 메뉴 전체 순서는 정확히 `대시보드, 질문학습, 질문연습, 탐구질문, 수업세션, 질문조회, 질문놀이, 학생관리, 설정`이다.
5. 학생과 교사 질문학습 경로가 같은 전체 슬라이드 경험을 사용한다.
6. 학생 질문연습에는 요약과 학생 경로 링크가 있고 전체 슬라이드는 없다.
7. 교사 직접 해보기에는 요약과 교사 경로 링크가 있고 전체 슬라이드는 없다.
8. 두 연습 요약에는 낱말보다 답에 필요한 사고가 기준이라는 안내와 유형별 대표 예시 한 개씩이 있다.
9. 공용 `QuestionPracticeView`는 질문학습 화면이나 역할별 경로를 가져오지 않는다.
10. 이전·다음과 진행 표시로 장을 이동하고 처음과 끝 경계를 넘지 않는다.
11. 왼쪽, 오른쪽, 처음, 끝 키가 올바른 장으로 이동한다.
12. 활성 진행 항목, 패널 이름과 현재 장 알림이 접근성 계약을 지킨다.
13. 즉석 확인 문제는 지역 상태에서만 채점하며 API를 호출하지 않는다.
14. 320픽셀, 390픽셀, 태블릿과 큰 화면에서 글, 버튼, 비교 자료가 겹치거나 잘리지 않는다.
15. 한국어와 영어 메뉴에서 항목이 넘치면 기존 더보기 메뉴로 안전하게 이동한다.

## 완료 기준

1. 학생과 교사 모두 대시보드 바로 오른쪽에서 질문학습에 들어갈 수 있다.
2. 두 역할이 같은 보완된 14장 학습 자료를 본다.
3. 두 질문연습 화면은 짧은 요약만 보여주고 각 역할의 전체 학습으로 이동한다.
4. 교사 전용 문항 은행, 학생 현황과 포인트 안내는 그대로 유지된다.
5. 전체 시험, 린트, 형 검사와 운영 빌드가 통과한다.
6. 모바일과 큰 화면의 실제 화면 검토에서 겹침, 잘림과 비정상 가로 넘침이 없다.
7. 변경을 기능 단위 커밋으로 만들고 원격 `main`에 푸시한다.
