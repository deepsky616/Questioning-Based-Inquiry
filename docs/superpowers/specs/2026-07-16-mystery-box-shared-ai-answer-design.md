# 친구방 미스터리박스 혼합 답변 설계

## 배경

친구와 함께하는 미스터리박스는 현재 에이아이 답변 기능을 사용하지 않는다. 서버의 고정 속성 규칙이 질문을 판정하며, 등록된 표현을 정확히 하나 찾지 못하면 `unknown`을 저장한다. 화면은 이를 `잘 모르겠어요`로 표시하므로 자연스러운 질문 대부분이 같은 답을 받는다.

## 목표

- 규칙으로 확실히 판정할 수 있는 질문은 기존처럼 빠르게 처리한다.
- 규칙 결과가 `unknown`인 정상 질문만 서버에서 에이아이로 보완한다.
- 비밀 물건 이름과 식별값은 클라이언트에 보내지 않는다.
- 에이아이 답변은 방에 한 번 저장하고 모든 참가자가 같은 결과를 본다.
- 에이아이 호출이 실패하면 질문, 점수, 차례를 소비하지 않고 다시 시도할 수 있게 한다.
- 기존 진행 방과 저장된 질문 기록을 계속 읽을 수 있게 한다.

## 검토한 방식

### 규칙 낱말만 확대

호출 비용은 없지만 학생의 다양한 표현을 계속 놓친다. 날기와 날개, 다리와 발처럼 서로 다른 사실을 한 속성으로 묶은 현재 자료에서는 낱말만 늘릴수록 틀린 답도 늘어난다.

### 모든 질문을 에이아이로 판정

표현 범위는 넓지만 이미 확실한 질문에도 지연과 비용이 발생한다. 에이아이 설정이 없거나 일시적으로 혼잡할 때 전체 놀이가 멈춘다.

### 규칙 우선, 에이아이 보완

확실한 질문은 규칙으로 즉시 처리하고, 규칙이 모르는 질문만 에이아이로 보완한다. 속도, 비용, 표현 범위, 장애 격리의 균형이 가장 좋으므로 이 방식을 사용한다.

## 처리 흐름

1. 방 요청을 기존 판정기에 먼저 넣어 참가 여부, 차례, 방 실행값, 라운드, 버전, 질문 형식, 질문 수 상한을 검증한다.
2. 실패 또는 재실행 결과면 기존 응답을 바로 반환하고 에이아이를 호출하지 않는다.
3. 규칙 결과가 `unknown`이면 판정기는 상태를 바꾸지 않고 서버 전용 `resolution-required` 결과를 돌려준다.
4. 질문한 학생을 기준으로 에이아이 설정을 찾고, 분당 별도 호출 제한을 적용한다.
5. 에이아이에는 비밀 물건과 학생 질문을 자료 객체로 전달하고 `yes`, `no`, `unknown` 중 하나만 구조화 응답으로 받는다.
6. 응답을 실행 중 검증한 뒤 서버 전용 해결값으로 원래 방 명령을 다시 판정한다. 클라이언트 본문의 답이나 출처는 사용하지 않는다.
7. 완성된 방 상태를 기존 버전 조건 저장으로 한 번 확정한다. 저장 충돌 시 최신 방을 덮어쓰지 않고 기존 재실행 또는 충돌 처리를 따른다.

## 상태 호환

질문 기록에 선택 항목 `answerSource?: "ai"`를 추가한다.

- 항목이 없으면 기존 기록이며 규칙 판정값과 저장 답이 같아야 한다.
- 값이 `ai`이면 서버에서 만든 구조화 답임을 뜻한다.
- 새 항목은 선택값이므로 기존 진행 방을 그대로 읽을 수 있다.
- 공개 방 기록에도 출처를 포함해 공개 상태 판독기가 같은 상태를 검증할 수 있게 한다.
- `private.itemId`는 기존 공개 변환에서 계속 제거한다.

서버 전용 해결값에는 `itemId`, `playerId`, `locale`, `question`, `answer`를 모두 넣는다. 판정기는 현재 상태와 네 바인딩 값이 모두 일치하고 기존 규칙 결과가 `unknown`일 때만 에이아이 답을 사용한다.

## 에이아이 경계

- 질문을 신뢰할 수 없는 자료로 취급하고 질문 안의 지시를 따르지 않게 시스템 지시를 고정한다.
- 숨은 물건은 판정에만 사용하며 출력하거나 되풀이하지 않게 한다.
- 일반적인 초등학생의 이해를 기준으로 참이면 `yes`, 거짓이면 `no`, 상황에 따라 달라지거나 모호할 때만 `unknown`을 고른다.
- 응답 형식은 제이슨 한 항목으로 제한하고 실행 중 엄격하게 다시 검증한다.
- 짧은 분류에 맞는 `gemini-2.5-flash-lite`를 고정하고 사고 예산은 영으로 둔다. 대체 플래시 모델에서도 사고 토큰이 출력 상한을 소진하지 않게 한다.
- 온도는 영, 출력 상한은 서른두 토큰, 요청 제한 시간은 팔 초로 둔다.
- 질문, 숨은 물건, 모델 원문은 오류 로그에 기록하지 않는다.

## 오류 처리

- 규칙 답변은 에이아이 설정과 관계없이 동작한다.
- 키 없음, 사용량 초과, 혼잡, 시간 초과, 파싱 실패, 허용되지 않은 답은 방을 저장하지 않는다.
- 응답에는 안전한 재시도 안내만 보내고 학생의 입력은 그대로 둔다.
- 질문은 기록되지 않고 점수와 차례도 바뀌지 않는다.
- 분당 에이아이 보완 호출을 사용자별 스무 번으로 제한한다.

## 시험 기준

- 등록된 질문은 에이아이를 호출하지 않고 기존 규칙 답을 저장한다.
- 자연스러운 미등록 질문은 에이아이의 예 또는 아니오 답과 `ai` 출처를 저장한다.
- 에이아이의 `unknown`도 구조적으로 저장하고 모든 참가자가 같은 값을 본다.
- 잘못된 출력, 호출 오류, 호출 제한에서는 저장하지 않는다.
- 잘못된 차례, 낡은 버전, 중복 명령에서는 에이아이를 호출하지 않는다.
- 클라이언트가 보낸 답과 출처는 무시한다.
- 기존 출처 없는 기록과 새 에이아이 기록을 모두 판독한다.
- 공개 응답에는 비공개 물건 정보가 포함되지 않는다.
- 관련 단위 시험, 방 경로 시험, 정적 검사와 전체 빌드가 통과한다.
