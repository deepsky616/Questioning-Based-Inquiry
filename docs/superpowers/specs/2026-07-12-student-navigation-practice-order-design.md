# 학생 질문연습 메뉴 순서 설계

## 목표

학생 공통 이동 메뉴에서 `질문연습`을 `질문하기` 바로 왼쪽으로 옮긴다.

최종 순서는 다음과 같다.

```text
홈 -> 질문연습 -> 질문하기 -> 질문탐구 -> 질문놀이 -> 설정
```

## 선택한 방식

`src/app/(student)/layout.tsx`의 공용 `STUDENT_PAGES` 배열 순서를 바꾼다. 상단 `AppNav`와 본문 아래 `PageNav`가 이 배열을 함께 사용하므로 두 메뉴의 표시 순서와 키보드 이동 순서가 동시에 일치한다.

CSS의 시각적 순서 속성은 사용하지 않는다. 화면에 보이는 순서와 문서 및 키보드 순서가 달라질 수 있기 때문이다.

## 변경 범위

- `STUDENT_PAGES`에서 `/student-practice` 항목을 `/student-ask` 바로 앞으로 이동한다.
- 학습 흐름 설명 주석을 실제 순서에 맞춘다.
- 학생 이동 메뉴 순서 시험을 새 순서에 맞게 고친다.

경로, 번역 문구, 화면 내용, 권한, API, 데이터베이스는 바꾸지 않는다.

## 시험

`student-navigation-order.test.ts`에서 다음 관계를 확인한다.

1. 질문연습은 질문하기보다 앞에 있다.
2. 질문하기는 질문탐구보다 앞에 있다.
3. 질문탐구는 질문놀이보다 앞에 있다.
4. 모든 메뉴 경로가 배열에 존재한다.

변경 뒤 해당 시험, 전체 린트와 운영 빌드를 실행한다.
