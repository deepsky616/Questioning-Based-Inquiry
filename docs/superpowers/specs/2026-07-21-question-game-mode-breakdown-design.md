# 질문놀이별 참여 방식 현황 설계

## 목표

교사와 학생이 질문놀이 참여 기록을 놀이별로 나누고, 각 놀이에서 혼자 하기, 인공지능과 함께, 친구와 함께를 얼마나 이용했는지 바로 비교할 수 있게 한다.

## 선택한 접근

- 기존 최근 6주 변화 그래프는 시간 흐름을 보여 주므로 유지한다.
- 기존 전체 방식 합계 그래프는 놀이별 방식 비교 그래프로 바꾼다.
- 교사 화면은 `참여 현황`과 기존 `완료율`을 같은 위치에서 전환한다.
- 학생 화면은 자신이 완료한 횟수를 놀이별 세 방식으로 보여 준다.
- 교사 화면에는 그래프 아래에 정확한 학생 수, 참여율, 완료 횟수를 표로 제공한다.

## 집계 기준

- 기존 완료 이력과 교사용 참여 통계를 읽기만 하며 포인트 기록은 변경하지 않는다.
- 학생 이력은 놀이와 방식별 완료 횟수를 집계한다.
- 교사 참여 현황은 선택 학급에서 각 방식으로 한 번 이상 참여한 학생 수를 사용한다.
- 교사 그래프의 막대 길이는 학급 학생 수 대비 참여 학생 비율이다.
- 교사 표에는 참여 학생 수와 완료 횟수를 함께 표시한다.
- 시작 횟수와 완료 횟수가 있는 기존 교사용 통계로 놀이별 완료율을 계속 제공한다.

## 화면 구성

### 학생과 개별 학생 보기

- 가로축은 완료 횟수, 세로축은 실제 기록이 있는 놀이이다.
- 각 놀이에 혼자 하기, 인공지능과 함께, 친구와 함께 막대를 나란히 표시한다.
- 전체 방식 합계는 기존 짧은 요약 줄에 유지한다.

### 교사 학급 보기

- `참여 현황`과 `완료율`을 분할 선택 단추로 전환한다.
- 참여 현황에서는 각 놀이의 방식별 참여율을 가로 막대로 표시한다.
- 도움말에는 참여 학생 수, 학급 인원, 참여율, 완료 횟수를 표시한다.
- 표는 놀이별 행과 세 방식별 열로 구성하고 `학생 수명, 완료 횟수회` 형식으로 표시한다.
- 완료율에서는 기존 놀이별 완료율 그래프를 유지한다.

## 빈 자료와 접근성

- 기록이 없는 놀이는 그래프와 표에서 숨긴다.
- 모든 놀이 기록이 없으면 기존 빈 자료 안내를 표시한다.
- 그래프에는 화면 읽기용 요약 목록을 함께 제공한다.
- 표 머리글과 그래프 설명은 밝은 화면과 어두운 화면의 공용 색상 값을 사용한다.

## 검사 계획

- 서버 집계가 놀이와 방식별 완료 횟수 및 참여 학생 수를 반환하는지 검사한다.
- 학생 화면이 놀이별 세 방식 완료 횟수를 표시하는지 검사한다.
- 교사 화면이 선택 학급의 학생만 포함해 참여율을 계산하는지 검사한다.
- 참여 현황과 완료율 전환, 정확한 수치 표, 빈 자료 상태를 검사한다.
- 전체 검사, 형 검사, 코드 검사와 제품 빌드를 실행한다.

## 범위에서 제외하는 항목

- 기존 질문놀이 기록이나 포인트를 다시 계산하거나 수정하지 않는다.
- 새로운 데이터베이스 표나 마이그레이션을 추가하지 않는다.
- 최근 6주 집계 기간은 변경하지 않는다.
- 놀이별 참여 목표나 교사 평가 기준은 추가하지 않는다.
