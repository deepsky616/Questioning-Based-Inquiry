# 질문연습 학습지 두 쪽 출력 설계

## 목표

교사 질문연습의 학생 배부용 학습지를 에이포 두 쪽으로 안정되게 출력한다. 첫째 쪽은 학생 정보와 질문 유형 이해하기, 둘째 쪽은 질문연습 활동이 인쇄 가능 영역의 하단까지 고르게 차도록 구성한다.

완료 조건은 다음과 같다.

- 머리말은 제목, 안내, 학년·반·번호, 이름 순서로 위에서 아래로 놓인다.
- 학년·반·번호는 같은 줄이고 이름은 바로 다음 줄에 단독으로 놓인다.
- 첫째 쪽에는 질문 유형 이해하기만, 둘째 쪽에는 질문연습 활동만 나온다.
- 두 쪽 모두 인쇄 가능 높이를 사용하며 내용 아래에 불필요한 큰 빈 공간이 남지 않는다.
- 글자와 테두리가 잘리지 않고 셋째 쪽이 생기지 않는다.
- 한국어와 영어 자료의 교육 내용과 답안 항목은 바꾸지 않는다.

## 검토한 방식

### 간격과 글자만 더 줄이기

수정량은 작지만 현재 문제를 만든 방식과 같다. 내용이 위에 몰리고 하단 높이를 사용하지 못하며 글자가 더 작아져 읽기 어려워진다.

### 설명이나 활동을 더 추가하기

용지를 채울 수 있지만 검증된 학습 내용을 바꾸고 학생의 작성 부담을 늘린다. 출력 배치 문제를 내용 변경으로 해결하므로 사용하지 않는다.

### 두 쪽을 독립 높이 영역으로 구성하기

각 쪽을 에이포 인쇄 가능 높이에 맞춘 영역으로 만들고 내부를 비율 격자로 배치한다. 내용은 유지하면서 카드와 답안 공간이 남은 높이를 사용하므로 이 방식을 선택한다.

## 화면 구조

인쇄 문서는 두 개의 `qp-sheet` 영역으로 나눈다.

첫째 쪽 `qp-sheet-guide`의 순서는 다음과 같다.

1. 학습지 제목
2. 한 줄 안내
3. 학년, 반, 번호 작성란
4. 이름 작성란
5. 질문 유형 이해하기 제목
6. 사실적, 개념적, 논쟁적 질문 설명

배부용 자료 표시는 화면 미리보기에서만 보여 주고 인쇄 머리말에서는 숨겨 제목이 첫 요소가 되게 한다. 제목과 안내 옆에 작성란을 놓는 현재 가로 배치를 없앤다. 작성란은 안내 아래에서 문서 너비를 사용한다. 이름 줄도 별도의 전체 너비 작성선을 제공한다.

둘째 쪽 `qp-sheet-activity`에는 질문연습 활동 제목과 활동 세 개만 둔다. 첫째 쪽에서 명시적으로 쪽을 나누고, 활동 영역 자체의 강제 앞쪽 나눔은 제거해 빈 쪽이나 셋째 쪽이 생기지 않게 한다.

## 높이 배분

인쇄 용지는 에이포, 바깥 여백은 기존 6밀리미터를 유지한다. 세로 사용 가능 높이 285밀리미터 가운데 1밀리미터를 인쇄 엔진 반올림 안전 폭으로 남기고 각 `qp-sheet` 높이를 284밀리미터로 고정한다. 모든 높이는 `border-box`로 계산하고 내용을 숨겨 맞추지 않는다.

- 첫째 쪽은 머리말의 실제 높이를 제외한 나머지를 질문 유형 영역에 준다.
- 질문 유형 카드 세 개는 같은 비율의 세 행으로 늘어난다.
- 각 유형 안의 세 가지 질문 만들기 방법도 카드 높이를 함께 사용한다.
- 둘째 쪽은 활동 제목을 제외한 나머지를 활동 카드 세 개에 같은 비율로 나눈다.
- 각 활동의 질문 행과 답안 작성란은 카드 안의 남은 높이를 사용한다.

고정 글자 축소로 용지를 맞추지 않는다. 본문은 11픽셀을 기준으로 하고 세부 설명도 10픽셀 아래로 낮추지 않는다. 높이는 카드와 답안 영역의 비율 배분으로 채우며 안쪽 여백과 줄 높이는 두 쪽 시험을 통과하는 값으로 고정한다.

## 화면 미리보기

일반 화면에서도 머리말 순서를 인쇄 결과와 같게 보여 준다. 두 쪽의 경계는 화면에서 24픽셀 간격으로 구분하되 카드 안에 카드를 겹쳐 보이게 만들지 않는다. 인쇄할 때만 그림자, 바깥 테두리, 화면 간격을 제거한다.

## 시험과 확인

- 화면 소스 시험으로 제목과 안내보다 학생 작성란이 뒤에 오는지 확인한다.
- 학년·반·번호 줄보다 이름 줄이 뒤에 오는지 확인한다.
- 두 `qp-sheet`와 첫째 쪽 뒤 쪽 나눔이 있는지 확인한다.
- 인쇄 스타일에 한 쪽 높이, 세 행 높이 분배, 늘어나는 답안 영역이 있는지 확인한다.
- 한국어와 영어 인쇄 화면을 실제 브라우저에서 PDF로 만들고 각각 정확히 두 쪽인지 확인한다.
- 각 쪽의 화면 또는 PDF 그림을 확인해 잘림, 겹침, 셋째 쪽, 과도한 하단 빈 공간이 없는지 검사한다.
- 관련 단위 시험, 린트, 타입 검사와 제품 빌드를 실행한다.

## 제외 범위

- 질문 유형 설명과 예시 내용 변경
- 활동 문항 수와 채점 방식 변경
- 다른 보고서와 일반 페이지의 인쇄 여백 변경
