# 질문수업 만들기와 관리 통합 설계

## 배경

교사의 주된 수업 만들기 흐름은 탐구질문 설계에서 시작한다. 교사는 교육과정과 성취기준을 고르고 핵심어, 핵심 문장, 핵심 질문과 탐구질문을 만든 뒤 날짜, 대상과 공개 설정을 정해 수업을 만든다. 학생은 연결된 참고 자료를 보고 질문을 작성한다.

별도 수업세션 화면은 설계가 연결되지 않은 빈 세션 생성 양식을 가장 위에 크게 보여 준다. 이 방식은 빠르게 질문만 받을 때 쓰는 부가 방식이지만 현재 화면에서는 주된 방식처럼 보인다. 탐구질문 수업을 만든 뒤에도 관리 목록으로 이동하지 않아 설계와 실제 수업의 연결도 약하다.

## 목표

1. 교사 상단 메뉴의 `탐구질문`과 `수업세션`을 `질문수업` 하나로 통합한다.
2. 질문수업 화면에서 탐구질문 방식을 주된 만들기 행동으로 보여 준다.
3. 기존 직접 생성 방식은 `간단 질문수업 만들기` 보조 행동으로 유지한다.
4. 탐구질문 수업 생성 뒤 관리 목록으로 이동해 새 수업을 확인할 수 있게 한다.
5. 기존 저장 자료, 관계, 내부 식별값, 자료 모형과 화면 주소를 유지한다.
6. 사용자에게 보이는 `수업세션` 용어를 문맥에 따라 `질문수업` 또는 `수업`으로 정리한다.

## 메뉴와 진입 화면

교사 상단 메뉴 순서는 다음과 같다.

1. 대시보드
2. 질문학습
3. 질문연습
4. 질문수업
5. 질문탐구
6. 질문놀이

`질문수업` 메뉴는 기존 질문수업 관리 주소를 사용한다. 기존 탐구질문 만들기 주소와 질문수업 관리 주소는 바꾸지 않아 저장된 즐겨찾기와 내부 연결을 보존한다.

질문수업 첫 화면은 다음 세 요소로 구성한다.

- 주 행동 `탐구질문으로 수업 만들기`
- 보조 행동 `간단 질문수업 만들기`
- `질문수업 목록`

주 행동은 채워진 단추로 먼저 보이고 기존 탐구질문 만들기 화면으로 이동한다. 보조 행동은 테두리 단추로 표시하며 눌렀을 때만 기존 직접 생성 양식을 펼친다. 두 방식을 같은 크기의 카드나 탭으로 나란히 두지 않는다.

## 탐구질문 수업 흐름

기존 다섯 단계 자료 생성과 저장 자료를 그대로 사용한다. 마지막 행동 이름은 `탐구질문 수업 만들기`로 바꾼다.

수업 생성이 성공하면 새 수업 식별값과 함께 질문수업 관리 화면으로 이동한다. 관리 화면은 해당 행으로 이동하고 잠시 강조한다. 새 수업에는 날짜, 교과, 주제, 대상, 공개 상태와 참여 현황을 기존 자료로 보여 준다.

저장한 탐구질문에서 실제로 새 수업을 만드는 행동은 `재배포`가 아니라 `이 설계로 새 수업 만들기`로 표현한다. 기존 연결 수업의 자료만 갱신하는 행동과 새 수업 생성 행동을 같은 용어로 부르지 않는다.

## 질문수업 종류와 상태

자료 판별 규칙은 기존 값을 사용한다.

- 설계 식별값이 있으면 `탐구질문 수업`
- 설계 식별값이 없으면 `간단 질문수업`

탐구질문 수업은 학생 질문 수집과 질문 정리 흐름으로 이어진다. 관리 행에서 학생 질문이 있으면 질문탐구 화면으로 이동하는 다음 행동을 제공한다. 새 표나 새 열을 만들지 않으며 현재 질문과 참여 자료에서 표시 상태를 계산한다.

## 용어 규칙

사용자에게 보이는 핵심 이름은 다음과 같다.

- 전체 기능: `질문수업`
- 설계 기반 방식: `탐구질문 수업`
- 직접 생성 방식: `간단 질문수업`
- 문맥상 분명한 날짜, 대상, 참여 문장: `수업`

화면 제목, 메뉴, 단추, 알림, 빈 화면, 분석 문구와 선택 항목에서 `수업세션`과 `수업 세션`을 사용하지 않는다. 문장이 어색해지는 경우 `질문수업`을 반복하지 않고 `수업`을 사용한다.

내부 코드는 바꾸지 않는다.

- `sessionId`
- `QuestionSession`
- 자료 조회와 저장 주소
- 자료 표와 열 이름
- 로그인 세션

## 자료 안전

- 자료 틀 변경과 자료 이전을 하지 않는다.
- 탐구질문 수업 생성은 기존 설계 저장 뒤 수업 생성 순서를 유지한다.
- 간단 질문수업 생성은 기존 수업 생성 요청을 그대로 사용한다.
- 기존 화면 주소를 삭제하지 않는다.
- 기존 학생 대상과 공개 설정 값을 그대로 전달한다.
- 생성 실패 시 관리 화면으로 이동하지 않고 현재 입력을 보존한다.

## 시험

- 교사 메뉴에 질문수업 하나만 나타나고 순서가 맞는지 검사한다.
- 질문수업 화면에서 탐구질문 행동이 주 행동이고 간단 생성 양식이 기본으로 닫히는지 검사한다.
- 간단 생성 요청 자료가 기존과 같은지 검사한다.
- 탐구질문 수업 생성 성공 뒤 새 수업 식별값으로 관리 화면에 이동하는지 검사한다.
- 관리 목록이 설계 연결 여부에 따라 두 종류를 정확히 표시하는지 검사한다.
- 한국어 화면 자료에 `수업세션`과 `수업 세션`이 남지 않는지 검사한다.
- 전체 자료 틀 차이 검사와 운영 빌드를 실행한다.
