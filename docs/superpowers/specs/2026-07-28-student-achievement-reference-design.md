# 학생 질문하기 성취기준 참고자료 설계

## 목표

탐구질문 수업에 참여하는 학생이 질문하기 화면의 참고자료에서 교사가 선택한 성취기준과 학생 눈높이의 쉬운 설명을 함께 확인할 수 있게 한다. 김질문 체험 계정에서도 같은 흐름을 바로 확인할 수 있어야 한다.

## 화면 구성

참고자료의 내용 순서는 다음과 같이 통일한다.

1. 핵심 아이디어
2. 성취기준
3. 핵심 문장
4. 핵심 질문
5. 탐구 질문

성취기준 영역은 다른 영역과 구분되는 청록 계열의 테두리와 배경을 사용한다. 밝은 화면과 어두운 화면에서 제목, 성취기준 번호, 본문, 쉬운 설명의 대비가 충분해야 한다.

성취기준마다 번호와 원문을 먼저 보여주고, 바로 아래에 `쉽게 풀어보기`라는 이름으로 학생용 설명을 보여준다. 쉬운 설명이 없는 기존 자료는 교육과정에 등록된 성취기준 해설을 대신 사용한다. 대체할 해설도 없으면 성취기준 원문만 보여주며 빈 설명이나 오류 문구는 표시하지 않는다.

## 자료 구조와 생성 흐름

기존 `learning_guides` 제이슨 자료에 성취기준별 설명 목록을 추가한다. 각 설명은 성취기준의 원래 순서를 가리키는 번호와 쉬운 설명을 가진다. 별도 데이터베이스 열은 추가하지 않는다.

교사가 `학생용 설명 만들기`를 누르면 기존 핵심 아이디어, 핵심 문장, 핵심 질문, 탐구 질문 설명과 함께 모든 선택 성취기준의 쉬운 설명을 한 번에 생성한다. 생성 요청에는 성취기준 번호와 원문을 포함하고, 응답 누락 시 기존 완전성 검사와 한 번의 보완 요청을 적용한다.

성취기준이 추가, 삭제, 수정되면 이전 학생용 설명은 오래된 자료로 판단한다. 교사가 다시 설명을 만들기 전에는 잘못 연결된 설명을 저장하거나 배포하지 않는다.

## 학생 참고자료 전달

수업 참고자료 길찾기는 `unit_designs.selected_achievements`와 `unit_designs.learning_guides`를 함께 읽어 학생 화면에 전달한다. 학생은 자신에게 배포된 수업만 조회할 수 있다는 기존 권한 경계를 유지한다.

다른 언어 화면에서는 성취기준 원문과 쉬운 설명도 기존 참고자료 번역 길찾기에 포함한다. 번역에 실패하면 한국어 원문을 유지하며 질문 작성은 계속할 수 있다.

## 기존 자료와 김질문 체험 자료

예전에 저장된 설계처럼 성취기준 설명이 없는 자료는 교과, 학년군, 영역, 성취기준 번호를 이용해 교육과정 해설을 찾는다. 교사가 직접 만든 번호처럼 일치하는 해설이 없으면 원문만 표시한다.

김질문 체험 계정의 모든 탐구 설계에는 수업 내용과 맞는 성취기준과 쉬운 설명을 명시적으로 넣는다. 체험 자료 다시 만들기를 실행해도 같은 자료가 만들어지도록 씨앗 자료와 검사를 함께 갱신한다.

## 오류 처리

- 성취기준 배열이 비어 있으면 성취기준 영역 전체를 숨긴다.
- 잘못된 설명 번호나 빈 설명은 정규화 단계에서 버린다.
- 인공지능 생성 결과가 일부 성취기준 설명을 빠뜨리면 보완 요청을 한 번 수행한다.
- 보완 뒤에도 불완전하면 부분 결과를 저장하지 않고 교사에게 다시 시도 안내를 보여준다.
- 교육과정 해설 조회나 번역 실패는 학생 질문 작성 기능을 막지 않는다.

## 검사와 배포

다음 동작을 자동 검사로 보장한다.

- 참고자료 길찾기가 성취기준과 학생용 설명을 반환한다.
- 성취기준 영역이 핵심 아이디어 다음에 표시되고 뒤 영역 번호가 알맞게 바뀐다.
- 학생용 설명 생성이 모든 성취기준 설명을 요구한다.
- 성취기준 변경 시 이전 설명을 최신 자료로 취급하지 않는다.
- 김질문 체험 자료에 성취기준과 쉬운 설명이 들어 있다.
- 밝은 화면과 어두운 화면에 필요한 색상 이름이 모두 적용된다.

구현 뒤 전체 자동 검사, 코드 검사, 운영 빌드를 통과시킨다. 작업 가지를 기본 가지에 병합하고 원격 저장소에 올린 뒤 운영 배포를 수행한다. 마지막으로 운영 사이트의 김질문 질문하기 화면에서 성취기준과 쉬운 설명의 순서와 표시를 확인한다.
