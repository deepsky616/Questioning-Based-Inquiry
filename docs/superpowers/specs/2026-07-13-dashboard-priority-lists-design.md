# 역할별 오늘 할 일 우선순위 목록 설계

## 배경

교사 대시보드는 다섯 개의 할 일 카드를 항상 보여 준다. 학생 대시보드는 여섯 개의 범주 카드와 최대 세 개의 교사 요청을 함께 보여 준다. 값이 0인 항목과 바로 행동할 필요가 없는 정보도 같은 크기와 색으로 표시되어, 사용자가 가장 먼저 해야 할 일을 찾기 어렵다.

교사의 추천 포인트와 부적절 의심 활동은 별도 조회가 끝나기 전 기본값 0으로 보일 수 있다. 학생의 댓글과 최근 포인트는 새 소식에 가깝지만 할 일 완료 상태를 계속 해제한다. 학생 화면의 최근 포인트는 바로 위 포인트 영역과도 겹친다.

## 목표

1. 오늘 할 일 영역 바깥 카드 하나는 유지한다.
2. 개별 카드는 한 줄 우선순위 목록으로 바꾼다.
3. 값이 0인 항목은 숨기고 최대 세 항목만 보여 준다.
4. 모든 자료 조회가 끝난 뒤에만 완료 상태를 보여 준다.
5. 교사와 학생에게 서로 다른 행동 우선순위를 적용한다.
6. 기존 질문, 알림, 포인트, 수업 자료를 수정하지 않는다.

## 교사 목록

교사 영역 제목은 `우선 확인`으로 바꾼다. 항목은 다음 순서로 정렬한다.

1. 부적절 의심 활동
2. 검토할 추천 포인트
3. 지도가 필요한 학생

`지도가 필요한 학생`은 선택한 학급 안에서 질문이 없거나 아직 질문하지 않은 수업이 남은 학생 식별값의 합집합으로 계산한다. 같은 학생을 두 번 세지 않는다. 활동 감소는 오늘 처리할 항목에서 제외하고 기존 학생 통계의 분석 정보로 유지한다.

추천 포인트와 부적절 의심 활동처럼 선택 기간을 따르지 않는 값은 기간 기준이라는 설명을 붙이지 않는다. 선택 학급 범위를 지원하지 않는 값은 전체 담당 범위임을 제목이나 보조 문구로 명확히 한다.

자료 조회가 진행 중이면 완료 상태를 표시하지 않는다. 일부 조회가 실패하면 0으로 간주하지 않고 다시 불러오기 행동을 제공한다.

## 학생 목록

학생 영역 제목은 `지금 할 일`로 바꾼다. 항목은 다음 순서로 정렬한다.

1. 선생님 요청
2. 오늘 질문할 수업
3. 최근 놓친 수업

교사 요청과 오늘 수업은 수업 식별값으로 겹침을 제거한다. 교사 요청에 포함된 수업은 오늘 질문할 수업 개수에서 다시 세지 않는다. 미래 수업, 배포 질문, 댓글, 최근 포인트는 오늘 할 일에서 제외한다. 기존 관련 화면과 알림 자료는 그대로 유지한다.

선생님 요청은 읽지 않은 고유 수업 요청 수를 보여 준다. 오늘 질문할 수업은 요청과 겹치지 않는 오늘 미작성 수업 수를 보여 준다. 최근 놓친 수업은 지난 미작성 수업 수를 보여 주되 목록에서는 한 항목으로 합친다.

## 표시 방식

각 행은 제목, 단위가 붙은 개수, 이동 화살표만 기본으로 보여 준다. 필요한 경우 한 줄짜리 수업명이나 범위만 보조 정보로 표시한다. 반복되는 설명, 백분율, 진행 막대와 `검토하기` 같은 명령 문구는 제거한다.

항목이 하나 이상이면 우선순위 순으로 최대 세 줄을 표시한다. 항목이 없고 모든 조회가 성공했으면 `지금 할 일이 없어요` 또는 `우선 확인할 일이 없습니다` 한 줄만 표시한다.

## 접근성과 반응형

- 각 행 전체를 단추로 사용하되 목적을 알 수 있는 접근성 이름을 제공한다.
- 키보드 초점과 밝은 화면, 어두운 화면의 대비를 유지한다.
- 작은 화면에서도 제목, 개수와 화살표가 겹치지 않도록 고정된 끝 열을 사용한다.
- 긴 수업명은 두 줄을 넘지 않는다.

## 시험

- 교사 항목의 위험도 순서와 0건 숨김을 검사한다.
- 교사 자료가 준비되지 않았을 때 완료 상태가 나오지 않는지 검사한다.
- 학생 목록에서 댓글, 포인트, 미래 수업과 배포 질문이 제외되는지 검사한다.
- 교사 요청과 오늘 미작성 수업의 중복 제거를 검사한다.
- 모든 항목이 없을 때 역할별 완료 문구를 검사한다.
