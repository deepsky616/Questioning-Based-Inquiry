# 질문놀이 입력 품질과 인공지능 주사위 차례 설계

## 목표

- 학생이 `그냥요?`, `몰라요?`, `왜요?`처럼 내용이 없는 질문을 제출해 놀이 차례나 점수를 얻지 못하게 한다.
- 정상적인 짧은 질문과 학습 과정에서 나온 틀린 시도는 과하게 차단하지 않는다.
- 질문 주사위의 인공지능 차례에서는 학생이 대신 주사위 단추를 누르지 않아도 자동으로 진행한다.
- 기존 질문놀이 기록, 점수, 방 상태와 자료 구조는 바꾸지 않는다.

## 선택한 방식

공통 질문 품질 판정은 확실한 회피성 표현, 내용 없는 의문사만의 질문, 반복 글자 입력만 차단한다. 질문 길이만 일괄적으로 늘리거나 모든 질문에 인공지능 판정을 강제하지 않는다. 이렇게 하면 응답 지연과 사용량 증가 없이 정상적인 짧은 사실 질문을 보존할 수 있다.

공통 판정은 지역 실행 서버와 친구 방 서버의 새 입력에만 적용한다. 저장돼 있는 예전 질문을 다시 판정하거나 고치지 않는다. 각 놀이의 기존 검사는 다음처럼 함께 유지한다.

- 이야기 주사위: 이야기 질문의 물음형 검사와 대답 관련성 검사
- 질문 주사위: 물음형, 중복과 서버 차례 검사
- 질문 릴레이: 물음형, 중복과 앞 질문 순서 검사
- 질문 사다리: 물음형, 비속어와 질문 확인 흐름
- 미스터리 박스: 예 또는 아니오로 답할 수 있는 질문 판정
- 까바놀이: 원문 대상과 행동 또는 상태 유지 판정
- 질문과 대답 짝 찾기: 학생 자유 입력이 없으므로 변경하지 않음

까바놀이에서는 회피성 입력만 제출 자체를 막고, 의미를 유지하려고 쓴 질문이 틀린 경우는 기존처럼 학습 시도로 기록한다.

## 질문 주사위 자동 차례

학생 질문이 저장되고 서버의 다음 단계가 인공지능 굴리기일 때 화면은 짧은 준비 상태를 보여 준 뒤 기존 서버 굴리기 동작을 자동 호출한다. 서버가 정한 주사위 눈을 기존 애니메이션으로 보여 준 다음 인공지능 질문을 만든다.

자동 굴리기가 실패하면 같은 요청을 계속 반복하지 않는다. 오류를 질문 주사위 가까이에 보여 주고 다시 굴리기 단추를 제공한다. 화면 이탈 시 예약된 자동 실행과 애니메이션을 모두 해제한다.

## 검증

- 공통 판정 단위 시험으로 한국어와 영어의 차단 및 허용 예시를 확인한다.
- 지역 실행 경로에서 무성의한 질문이 활동과 점수에 기록되지 않는지 확인한다.
- 친구 방의 이야기 주사위, 질문 주사위, 질문 릴레이와 까바놀이가 같은 입력을 거절하는지 확인한다.
- 질문 주사위 화면에서 학생 제출 뒤 별도 누름 없이 인공지능 굴리기와 질문 생성이 이어지는지 확인한다.
- 자동 굴리기 실패 시 무한 반복 없이 다시 시도할 수 있는지 확인한다.
