# 탐구 질문 배포 자료 확인 화면 설계

## 목표

탐구 질문 만들기의 다섯째 단계를 질문 편집과 학생 배포 자료 확인으로 분리한다. 교사는 먼저 사실적, 개념적, 논쟁적 질문만 작성하거나 수정하고, 완료한 뒤 단원 전체 자료를 읽기 전용으로 확인한다. 학생용 설명은 한 번의 인공지능 요청으로 생성하며 각 원문 바로 아래에서 확인하고 수정할 수 있다.

## 현재 문제

- 다섯째 단계에 탐구 질문 편집, 학생용 설명, 저장 정보, 배포 설정이 한꺼번에 나타나 작업 순서가 불명확하다.
- 학생용 설명이 원문과 함께 편집 화면에 노출되어 질문 작성에 집중하기 어렵다.
- 핵심 낱말이 인공지능 응답 품질에 따라 누락되거나 개수가 부족할 가능성이 있다.
- 원문이 바뀐 뒤 이전 학생용 설명이 그대로 남으면 서로 어긋난 자료가 배포될 수 있다.

## 선택한 접근

별도의 여섯째 단계를 추가하지 않고 다섯째 단계 내부에 두 가지 화면 상태를 둔다.

1. `질문 편집` 상태
2. `배포 자료 확인` 상태

이 방식은 기존 다섯 단계 진행 구조를 유지하면서도 작업 목적을 명확히 분리한다. 접기와 펼치기로 모든 기능을 한 화면에 두는 방식은 현재의 정보 과밀 문제를 해결하지 못하므로 사용하지 않는다.

## 화면 흐름

### 질문 편집 상태

- 사실적, 개념적, 논쟁적 질문 카드만 표시한다.
- 각 카드는 유형 변경, 내용 수정, 순서 변경, 삭제를 지원한다.
- 새 질문 추가도 세 유형만 제공한다.
- 학생용 설명, 단원 저장 정보, 학생 배포 설정은 표시하지 않는다.
- 내용이 있는 탐구 질문이 한 개 이상일 때만 `탐구 질문 만들기 완료` 버튼을 활성화한다.
- 완료 버튼을 누르면 빈 질문을 제외하고 배포 자료 확인 상태로 전환하며 화면 상단으로 이동한다.

### 배포 자료 확인 상태

- 제목과 안내 문구로 현재 화면이 학생에게 전달할 자료의 최종 확인 단계임을 알린다.
- 다음 원문을 읽기 전용으로 표시한다.
  1. 단원명
  2. 핵심 아이디어
  3. 핵심 문장
  4. 핵심 질문
  5. 탐구 질문
- 단원명이 비어 있으면 `질문 수업을 만들 때 단원명을 입력해 주세요`라는 안내를 표시한다.
- 하단 저장 영역에서 단원명을 입력하면 상단의 단원명 표시도 즉시 갱신한다.
- `학생용 설명 만들기` 버튼은 모든 영역의 설명을 한 번에 생성한다.
- 생성된 설명은 해당 원문 바로 아래에 나타나며 교사가 직접 수정할 수 있다.
- `탐구 질문 수정하기` 버튼을 누르면 질문 편집 상태로 돌아간다.
- 질문 원문이 변경되면 이전 설명은 최신 자료로 인정하지 않으며 다시 만들기 안내를 표시한다.

## 자료 표시와 색상 체계

기존 제품의 카드와 입력 요소를 유지하고 영역별 의미 색상을 사용한다.

- 단원명: 중립 회색
- 핵심 아이디어: 주황
- 핵심 문장: 하늘색
- 핵심 질문: 보라색
- 탐구 질문: 초록색

각 영역은 다음 구조를 공유한다.

- 상단: 번호, 그림 표시, 영역명, 짧은 설명
- 본문 첫 부분: 진한 글자의 읽기 전용 원문
- 본문 둘째 부분: 옅은 내부 패널의 학생용 설명
- 핵심 낱말: 낱말과 뜻을 함께 보여주는 작은 이름표 또는 편집 영역
- 설명 생성 전: 빈 입력칸 대신 생성 안내

밝은 테마에서는 옅은 배경과 진한 글자를 사용하고, 어두운 테마에서는 어두운 배경과 밝은 글자를 사용한다. 색상만으로 영역을 구분하지 않고 번호, 제목, 그림 표시를 함께 제공한다. 입력 요소는 제품의 `배경`, `앞쪽 글자`, `입력 테두리` 색상 값을 사용한다.

## 학생용 설명 자료 구조

한 번의 생성 요청으로 다음 내용을 모두 반환한다.

- 핵심 아이디어
  - 쉬운 설명
  - 생활 속 연결
  - 핵심 낱말 3개에서 5개
- 모든 핵심 문장
  - 문장마다 쉬운 설명 한 개
- 모든 핵심 질문
  - 질문마다 생각할 범위 한 개
  - 짧은 관점 2개에서 3개
- 모든 탐구 질문
  - 질문이 묻는 뜻 한 개
  - 핵심 낱말 2개에서 5개
  - 생각을 시작할 단서 한 개

핵심 낱말은 앞 단계에서 선택한 핵심어를 우선한다. 낱말은 서로 중복되지 않아야 하며 모든 낱말에는 학생 눈높이의 뜻이 있어야 한다.

## 생성 결과 검증과 자동 보완

인공지능의 의미 판단을 절대적으로 보장할 수는 없으므로, 자동화에서는 빈칸, 누락, 중복, 개수 부족이 없는 형식적 완전성을 보장하고 교사가 최종 문구를 수정할 수 있게 한다.

서버는 학생용 설명 응답을 적용하기 전에 다음을 검사한다.

- 핵심 아이디어 핵심 낱말이 3개에서 5개인지
- 모든 핵심 낱말에 낱말과 뜻이 모두 있는지
- 같은 영역 안에 중복 낱말이 없는지
- 모든 핵심 문장에 쉬운 설명이 있는지
- 모든 핵심 질문에 생각할 범위와 관점이 있는지
- 모든 탐구 질문에 뜻, 핵심 낱말 2개 이상, 생각 단서가 있는지
- 원래 배열 번호와 생성 결과의 번호가 정확히 대응하는지

첫 응답이 이 기준을 통과하지 못하면 누락 항목과 잘못된 항목을 포함한 보완 요청을 서버에서 한 번 자동 실행한다. 보완 결과까지 기준을 통과한 경우에만 전체 결과를 반환한다. 두 번 모두 실패하면 부분 결과를 적용하지 않고 명확한 다시 시도 안내를 반환한다.

## 최신 상태 판별

설명 생성에 사용한 다음 원문으로 서명을 만든다.

- 핵심 아이디어
- 선택된 핵심 문장
- 선택된 핵심 질문
- 내용이 있는 탐구 질문의 유형과 내용

생성 성공 시 이 서명을 함께 보관한다. 현재 원문의 서명과 다르면 기존 설명은 오래된 상태로 취급한다. 오래된 설명은 학생 배포 자료로 표시하지 않고 `원문이 바뀌었어요. 학생용 설명을 다시 만들어 주세요`라는 안내와 다시 만들기 버튼을 제공한다.

## 저장과 질문 수업 생성

- 학생용 설명 생성은 선택 사항으로 유지한다.
- 단원명, 날짜, 학년, 대상과 공개 설정은 배포 자료 확인 화면 하단에 둔다.
- 단원명이 비어 있으면 저장과 질문 수업 생성 버튼을 비활성화한다.
- 저장 자료에는 최신 상태의 학생용 설명만 포함한다.
- 오래된 설명은 저장 요청에서 제외한다.

## 오류 처리

- 생성 중에는 버튼을 비활성화하고 진행 상태를 표시한다.
- 생성 실패 시 기존의 최신 설명은 보존한다.
- 첫 생성이 실패한 경우 빈 설명 편집칸을 노출하지 않고 다시 시도 안내를 표시한다.
- 질문이 모두 비어 있으면 완료 버튼을 비활성화하고 이유를 안내한다.
- 저장 또는 질문 수업 생성 실패 시 현재 배포 자료와 입력값을 보존한다.

## 구성 요소 경계

- 다섯째 단계 구성 요소는 편집 상태와 배포 자료 확인 상태의 전환을 담당한다.
- 질문 편집 목록은 질문 유형과 내용 편집만 담당한다.
- 배포 자료 확인 구성 요소는 읽기 전용 원문과 학생용 설명을 영역별로 배치한다.
- 학생용 설명 생성 훅은 생성 중 상태, 결과 적용, 최신 상태 서명을 담당한다.
- 서버 검증 도우미는 생성 결과의 완전성 검사와 보완 요청에 사용할 오류 목록 생성을 담당한다.

## 검사 계획

### 단위 검사

- 핵심 낱말 개수, 빈 뜻, 중복 낱말을 거부한다.
- 모든 문장과 질문의 번호 대응을 검사한다.
- 완전한 결과만 통과시킨다.
- 원문 변경 전후의 설명 최신 상태를 정확히 판별한다.

### 화면 검사

- 질문 편집 상태에는 세 질문 유형과 편집 기능만 표시한다.
- 완료 버튼을 누르면 배포 자료 확인 상태로 전환한다.
- 원문은 읽기 전용이고 학생용 설명만 수정할 수 있다.
- 각 설명은 대응하는 원문 바로 아래에 표시한다.
- 단원명 입력이 상단 표시와 즉시 동기화된다.
- 다섯 영역의 색상과 밝은 테마, 어두운 테마 글자 대비용 색상 값이 적용된다.
- 원문 변경 뒤 오래된 설명을 배포 자료로 표시하지 않는다.

### 전체 흐름 검사

- 교사 로그인부터 다섯째 단계 질문 편집까지 진행한다.
- 완료 버튼으로 배포 자료 확인 화면에 진입한다.
- 학생용 설명 만들기 뒤 모든 영역과 핵심 낱말을 확인한다.
- 단원명을 입력하고 설계 저장까지 완료한다.
- 저장된 자료에 최신 학생용 설명이 포함되는지 확인한다.

## 완료 기준

- 다섯째 단계 편집 화면에는 사실적, 개념적, 논쟁적 질문만 보인다.
- 완료 뒤 단원명, 핵심 아이디어, 핵심 문장, 핵심 질문, 탐구 질문이 읽기 전용으로 보인다.
- 학생용 설명 만들기 한 번으로 모든 필수 설명이 원문 아래에 나타난다.
- 핵심 아이디어의 핵심 낱말은 3개에서 5개이며 뜻과 함께 자동 입력된다.
- 각 탐구 질문의 핵심 낱말은 2개에서 5개이며 뜻과 함께 자동 입력된다.
- 불완전한 인공지능 응답은 자동 보완을 거치며 끝까지 불완전하면 적용되지 않는다.
- 밝은 테마와 어두운 테마에서 원문과 설명을 읽을 수 있다.
- 기존 저장과 질문 수업 생성 기능의 검사에 회귀 오류가 없다.

## 범위에서 제외하는 항목

- 기존 다섯 단계 진행 표시를 여섯 단계로 변경하지 않는다.
- 학생 화면의 별도 새 페이지는 만들지 않는다.
- 인공지능 모델 선택 정책은 변경하지 않는다.
- 저장된 과거 설계 자료를 일괄 다시 생성하지 않는다.
