# 자료 접근 경계 보완 구현 계획

> **작업자 안내:** 각 작업은 실패하는 검사부터 시작하며 `superpowers:subagent-driven-development` 또는 `superpowers:executing-plans` 방식으로 진행한다.

**목표:** 학교, 담당 학급, 질문수업 배정 범위를 서버에서 일관되게 강제한다.

**구조:** 교사와 학생 범위 판정을 작은 공통 도움 함수로 모으고, 각 경로는 자료를 읽거나 쓰기 전에 이를 호출한다. 질문 목록처럼 자료 저장소 조건이 중요한 곳은 결과를 받은 뒤 거르지 않고 조회 조건 자체에 접근 범위를 넣는다.

**기술 구성:** 다음 서버 경로, 타입스크립트, 프리즈마, 비테스트

## 공통 제약

- 기존 자료와 데이터베이스 표 구조를 변경하지 않는다.
- 학교가 없거나 대상 관계가 불분명하면 접근을 허용하지 않는다.
- 담당 학급이 없는 교사는 현재 제품 규칙대로 같은 학교 학생 범위를 사용한다.
- 모든 동작 변경에는 실패가 먼저 확인된 회귀 검사를 둔다.
