# 질문 연구소의 학생 AI 윤리교육

## 화면 구성

| 위치 | 추가한 내용 | 사용 방법 |
| --- | --- | --- |
| 학생 질문학습 | AI 사용 약속 탭 | 여섯 가지 약속 → 세 상황 판단 → 오늘의 실천 약속 선택 |
| 교사 질문학습 | AI 사용 약속 탭 | 학생과 같은 활동을 살펴보고 ‘약속 수업 화면으로 보기’로 토의 진행 |
| 교사 질문학습의 수업 활용 | 첫 사용 전 20분 수업안 | 활동 시간·발문·실천 관찰 기준 확인 |
| 질문 작성 | 자기 생각과 개인정보 안내 | 작성 중 ‘사용 약속 보기’를 열어도 질문과 수업 선택 유지 |
| 질문 분석 결과 | AI의 한계와 학생 판단 안내 | 제안과 원래 질문의 뜻을 비교한 뒤 수정 여부 결정 |
| 학생 댓글 | 존중·개인정보·교사에게 알리기 안내 | 댓글 초안을 유지하며 약속 확인 |
| 질문놀이 목록 | 점수보다 질문의 이유를 생각하는 안내 | 놀이를 선택하기 전에 확인 |
| 성장 기록 | 도움받은 내용과 자기 판단을 밝히는 문장 틀 | 문장 틀을 참고해 직접 작성 |

바로가기 주소는 `/student-question-learning#ai-ethics`와 `/teacher-question-learning#ai-ethics`이다. 기존 로그인·역할별 접근 제어를 그대로 적용한다.

## 수업에서 사용하는 순서

1. 첫 사용 전에 교사가 수업 활용의 20분 수업안을 확인한다.
2. 큰 화면으로 여섯 약속을 읽고 상황별 행동의 이유를 이야기한다.
3. 학생은 세 상황에서 행동을 고른다. 다시 생각할 선택에는 이유를 보여 주고 재선택하게 한다.
4. 오늘 실천할 약속 하나를 선택하고 질문 활동으로 이동한다.
5. 이후 차시마다 시작과 끝에 1분씩 개인정보·AI 제안 검토·존중·도움 표시를 돌아본다.
6. 성장 기록에는 제안을 받아들이거나 거절한 이유를 자기 말로 남긴다. 도움을 받지 않았다면 스스로 고친 과정을 쓴다.

## 기록과 동작 범위

- 약속과 상황 판단은 정적인 교육 자료이며 외부 AI를 호출하지 않는다.
- 연습 선택은 현재 열린 학습 화면의 상태로만 유지한다. 새로고침하거나 페이지를 벗어나면 초기화되며 학생별 이수 기록·윤리 점수로 저장하지 않는다.
- 탭만 전환하면 질문학습의 장과 윤리교육의 연습 위치를 유지한다.
- 단계별 ‘사용 약속 보기’는 현재 화면 안의 대화상자다. 작성한 질문·댓글·성장 기록을 자동 제출하거나 덮어쓰지 않는다.
- 학생의 약속 선택만으로 윤리 실천이나 수업 효과가 입증되었다고 해석하지 않는다. 질문·댓글·성장 기록과 수업 대화에서 실제 행동을 확인한다.
- 교사에게 알리라는 안내는 교사와 대화하도록 안내하는 내용이다. 새 신고 기능이나 자동 개인정보 차단 기능을 추가한 것은 아니다.
- 이 교육 자료는 외부 AI 서비스의 이용 조건이나 학교의 개인정보 처리 기준을 대신하지 않는다.

## 동료교사 시범운영 기록 양식

아래 표는 앞으로 실제 운영 후 작성한다. 개발 시점이나 시험 결과를 과거 수업 실적으로 소급해서 기록하지 않는다.

| 실제 적용일·대상 | 관찰한 어려움과 근거 | 개선한 화면·문구 | 다음 적용일 | 다시 확인한 변화 |
| --- | --- | --- | --- | --- |
| 직접 기록 | 학생 발언·교사 관찰·비식별 예시 | 실제 변경 사항과 버전 | 직접 기록 | 같은 기준으로 관찰한 결과 |

관찰 질문:

- 교사의 추가 설명 없이 ‘AI 사용 약속’을 찾을 수 있었는가?
- 개인정보가 포함된 질문을 학생이 직접 고쳤는가?
- AI 제안의 수용·거절 이유를 말할 수 있었는가?
- 친구의 질문 유형을 낮춰 보지 않고 이유를 담아 댓글을 썼는가?
- 성장 기록에서 도움받은 부분과 자기 판단을 구별했는가?
- 작은 화면·키보드·어두운 테마에서 읽거나 조작하는 데 어려움이 있었는가?
