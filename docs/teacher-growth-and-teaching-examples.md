# 교사 성장 기록 비교와 담당 학년별 질문 수업 예시

## 교사 상세리포트

- 수업별로 학생이 직접 작성한 성장 기록을 읽기 전용으로 표시한다. 넓은 화면에서는 `처음 질문 / 고친 질문`, `질문을 만들거나 고친 점 / 탐구하며 알게 된 점`의 2×2 배열이고, 작은 화면에서는 같은 순서의 한 열이다.
- 교사 화면의 빈 메모에는 `미작성`, 처음 질문과 같은 고친 질문에는 `질문을 수정하지 않음`을 표시한다. 학생의 원문을 임의로 채우지 않는다.
- 출력본은 같은 순서의 2열 배열이다. 빈 항목과 상태 안내를 생략하고, 수정하지 않은 질문은 `나의 질문`으로 한 번만 출력한다.
- 학생용 작성 양식과 상세리포트, 수업별 조회·페이지 이동·최근 수정일·권한 확인은 기존 동작을 유지한다.

## 질문학습의 수업 활용

- 로그인한 교사의 `teacherClass`에서 담당 학년만 읽는다. 같은 학년의 여러 반은 중복을 제거하고, 여러 담당 학년이 있으면 선택할 수 있다.
- 초등 1~6학년에 서로 다른 두 교과 주제를 마련했다. 기존 여섯 안내 패널마다 같은 두 주제를 해당 질문 유형에 맞게 제시하여 비교할 수 있다.
- 5학년은 과학 `용해와 용액`, 수학 `평균으로 자료 비교하기`이다. 준비 안내, 활용 질문, 수업 진행 방법을 함께 제공한다.
- 자체 작성한 질문과 성취기준 원문을 구분한다. 성취기준은 `src/data/curriculum-achievements.json`에서 코드와 원문을 함께 연결하며, 목록에서 펼쳐 확인한다.
- 교육과정의 성취기준은 학년군 기준이다. 화면에 학년군을 안내하고 실제 수업 진도에 맞춰 사용하도록 설명한다. 성취기준 코드의 숫자만으로 개별 학년을 추정하지 않는다.
- 담당 학년이 없으면 학급 설정을 안내한다. 조회 실패 시 일반 수업 안내는 유지하고 예시 재시도 버튼을 제공한다. 다른 교사의 학급이나 임의 학년으로 대체하지 않는다.
- 예시와 활용 안내는 한국어·영어를 제공한다. 성취기준은 영어 화면에서도 한국어 원문임을 명시한다. 전체 교육과정 자료는 서버에서 조회하고 필요한 예시만 화면으로 전달한다.
- `열린 질문과 닫힌 질문` 패널 하단에 `닫힌 질문 진단 보기`, `열린 질문 진단 보기`를 제공한다. 각각 기존 학급 학습 현황의 해당 진단 유형으로 바로 이동한다.

## 검증

- 단위 검사: 담당 교사 인증, 학년 중복 제거·선택·미지정·조회 실패, 1~6학년별 교과와 성취기준 연결, 한국어·영어 예시, 두 진단 경로, 교사 읽기 전용 표시, 모든 작성 기록 출력과 빈 항목 생략.
- 브라우저 검사: 성장 기록 작성·수업별 조회·출력, 교사 기록의 375/768/1440 화면과 밝은·어두운 테마, 기존 언어 전환과 학생 연습 현황.
- 실제 담당 5학년 자료로 네 가지 언어·테마·화면 크기 조합에서 예시 12개, 성취기준 원문, 두 진단 버튼의 이동과 선택 상태, 가로 넘침·화면 오류 여부를 확인했다.
- 17개 성장 기록을 담은 5쪽 출력 파일의 처음과 마지막 쪽을 확인했다. 모든 기록이 포함되고 빈 마지막 쪽이나 미작성 상태 안내가 없다.
- 데이터베이스 스키마·기록 저장·진단 계산은 변경하지 않으며, 시연 자료를 재생성하지 않는다.
