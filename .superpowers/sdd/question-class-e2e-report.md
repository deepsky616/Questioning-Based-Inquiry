# 질문수업 최종 브라우저 시험 보고서

## 시험 범위

- 교사 대시보드의 `우선 확인` 세 줄과 순서
- 질문수업 메뉴의 대표 주소와 탐구질문 화면 별칭 활성 상태
- 질문수업 관리 화면의 탐구질문 주 행동
- 간단 질문수업 만들기의 기본 닫힘, 펼침과 닫기 이름 변화
- 학생 대시보드의 `지금 할 일` 세 줄, 순서와 교사 요청 중복 제거
- 교사 대시보드, 질문수업 관리, 탐구질문, 학생 대시보드의 가로 넘침

## 자료 보호

- 실행 대상마다 분리된 합성 교사와 학생만 준비하고 시험 뒤 정리한다.
- 질문, 질문수업, 알림과 포인트 조회는 고정 응답으로 대신한다.
- 가로챈 주소에 조회가 아닌 요청이 들어오면 기록하고 요청을 막는다.
- 간단 만들기는 펼치기까지만 확인하며 저장 단추를 누르지 않는다.
- 학생 우선 할 일 행도 누르지 않아 알림 읽기 요청을 보내지 않는다.
- 운영 자료, 자료 틀, 내부 식별값과 저장 주소는 바꾸지 않는다.

## 실패에서 확인한 시험 보완

1. 로그인 직후 상단 영역이 나타나기 전에 넘침 메뉴를 찾던 시험을 고쳤다.
2. 펼친 뒤 이름이 바뀐 제어 단추 대신 안쪽 제출 단추를 다시 찾던 선택자를 고쳤다.
3. 숫자 반만 받는 로그인 입력과 맞지 않던 합성 반 이름을 숫자로 바꿨다.

제품 기능이나 운영 자료의 오류가 아니라 시험 준비와 선택자 문제였으며, 제품 코드는 수정하지 않았다.

## 최종 결과

- 데스크톱 단독: 2건 통과
- 태블릿 단독: 2건 통과
- 데스크톱과 태블릿 묶음: 4건 통과, 실패 0건
- 네 주요 화면 가로 넘침: 0건
- 예상하지 않은 쓰기 요청: 0건
