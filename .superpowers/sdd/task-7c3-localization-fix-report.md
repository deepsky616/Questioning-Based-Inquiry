# 작업 7 지역 이야기 주사위 영어 대체 자료 보정

- 제품 커밋: `3104a25`
- 잘못된 단어 응답에서 만든 이중 언어 대체 자료를 영어 화면의 단어 목록, 굴림 결과, 이야기 입력 안내와 인공지능 질문 문맥에 영어로 표시하도록 보정했다.
- 정상 인공지능 단어는 표시값이 없을 때 기존 원문을 그대로 유지한다.

## 시험 우선 기록

- 영어 화면에 잘못된 단어 응답을 주는 회귀 시험을 먼저 추가했다.
- 구현 전에는 영어 단어를 찾지 못하고 한국어 대체 단어가 표시되어 실패했다.
- 구현 뒤 지역 라운드 한 파일의 스무 시험이 통과했다.

## 최종 검증

- 지역 라운드, 질문놀이 지역화, 이야기 단어 그림 시험: 세 파일 서른여섯 시험 통과
- 변경 파일 이슬린트: 통과
- 전체 자료형 검사: 통과
- 변경 파일 공백 검사: 통과
