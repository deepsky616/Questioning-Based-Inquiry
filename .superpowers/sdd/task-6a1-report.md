## 시험 우선 확인

1. 제품 모듈을 만들기 전에 순수 규칙 시험을 먼저 작성했다.
2. 첫 실행은 `@/lib/question-ladder` 모듈을 찾을 수 없어 시험 묶음이 실패했다.
3. 최소 구현 뒤 생성, 추적, 경로와 배정 시험 49개가 통과했다.
4. 자기 검토에서 칸이 비어 있는 주제 배열이 배열 순회에서 빠지는 문제를 찾았다.
5. 이 입력을 거절하는 시험이 49개 통과와 1개 실패로 재현되는 것을 확인했다.
6. 모든 칸을 직접 검사하도록 고친 뒤 최종 50개가 통과했다.

## 구현 결과

- `generateLadderGrid`는 2개부터 8개 열과 10개 행을 만들고, 같은 행에서 서로 맞닿는 발판을 만들지 않는다.
- 난수 공급자가 돌려준 모든 값은 유한한 0 이상 1 미만인지 검사하며 잘못된 값은 거절한다.
- `traceLadderColumns`는 시작 열과 각 행을 지난 열을 순서대로 돌려준다.
- `buildLadderPathSegments`는 논리 좌표만 사용해 연속된 세로선과 실제 가로 발판을 만들며 대각선이나 이전 열의 여분 선을 만들지 않는다.
- `assignLadderTopics`는 추적 도착 열의 주제를 시작 열에 배정하고 입력 배열을 바꾸지 않는다.
- 빈 발판, 잘못된 행 너비와 열 범위, 맞닿은 발판, 잘못된 시작 열, 주제 수와 주제 자료를 명확히 거절한다.
