6. 모든 칸을 직접 검사하도록 고친 뒤 최종 50개가 통과했다.

## 독립 검토 보정

1. 생성 함수는 10개 행을 만들지만 소비 함수는 비어 있지 않은 임의 행 수를 받는다는 중요 지적을 확인했다.
2. 고정 시험 사다리를 기존 앞 3개 이동 행과 뒤 7개 빈 발판 행으로 구성해 도착 관계를 보존했다.
3. 행 수 1, 9, 11을 추적, 경로와 배정 함수에 넣었을 때 52개 통과와 3개 실패로 문제를 재현했다.
4. 바깥 배열과 안쪽 행의 비어 있는 칸은 기존 칸 검사가 이미 거절하는 것도 함께 확인했다.
5. 공통 그리드 검증이 정확히 `LADDER_ROW_COUNT`인 10개 행만 받도록 고쳤다.
6. 잘못된 행 너비, 맞닿은 발판, 열 범위와 발판 값 시험도 10개 행 자료로 바꿔 행 수 검사가 세부 오류를 가리지 않게 했다.
7. 추적 결과는 시작 열을 포함한 11개 열 기록이며 경로 마지막 높이는 10이다. 옆 열로 이동한 뒤 예전 시작 열 아래에 여분 선이 없는 시험도 계속 통과한다.

## 구현 결과

- `generateLadderGrid`는 2개부터 8개 열과 10개 행을 만들고, 같은 행에서 서로 맞닿는 발판을 만들지 않는다.
- 난수 공급자가 돌려준 모든 값은 유한한 0 이상 1 미만인지 검사하며 잘못된 값은 거절한다.
- `traceLadderColumns`는 시작 열과 각 행을 지난 열을 순서대로 돌려준다.
- `buildLadderPathSegments`는 논리 좌표만 사용해 연속된 세로선과 실제 가로 발판을 만들며 대각선이나 이전 열의 여분 선을 만들지 않는다.
- `assignLadderTopics`는 추적 도착 열의 주제를 시작 열에 배정하고 입력 배열을 바꾸지 않는다.
- 10개가 아닌 행 수, 희소 배열, 잘못된 행 너비와 열 범위, 맞닿은 발판, 잘못된 시작 열, 주제 수와 주제 자료를 명확히 거절한다.
