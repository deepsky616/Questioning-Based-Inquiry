# 작업 7 지역 모드 마지막 점검 보고서

## 결과

- 상태: 제품 보정 완료
- 구현 커밋: `87512b2`
- 변경 파일: 질문 주사위 화면, 이야기 주사위 화면, 지역 라운드 시험
- 허용 범위 밖 병행 변경은 제품 커밋에 넣지 않았다.

## 시험 우선 기록

1. 혼자와 인공지능 질문 주사위에서 굴림 뒤 질문 제출 전 재굴림 단추가 없어야 하는 시험을 먼저 추가했다.
2. 두 모드 모두 기존 재굴림 단추가 남아 있어 예상대로 실패했다.
3. 이야기 단어 응답의 빈 객체, 일부 범주만 있는 객체, 빈 범주 배열과 제한보다 긴 단어 시험을 먼저 추가했다.
4. 빈 객체와 일부 범주는 화면 오류, 빈 배열과 긴 단어는 안전한 대체 실패로 예상대로 실패했다.
5. 화면과 판독을 보완한 뒤 대상 시험 열아홉 개가 모두 통과했다.

## 구현 계약

- 질문 주사위 굴림 함수는 단계가 `idle`이고 기존 굴림 타이머가 없을 때만 실행한다.
- 질문 작성 단계에서는 재굴림 단추를 보여 주지 않는다.
- 이야기 단어 응답의 `parsed` 객체도 바로 믿지 않고 문자열로 바꿔 기존 `parseAIWords` 판독을 거친다.
- 세 범주 모두 여섯 개 이상이며, 각 단어가 공백 없이 비어 있지 않고 길이 제한 안이며 범주 안에서 겹치지 않을 때만 사용한다.
- 판독할 수 없는 객체와 본문은 범주마다 여덟 단어와 한국어 및 영어 표시값을 가진 `pickFallbackBilingualWords` 결과로 바꾼다.
- 요청이 화면 종료 뒤 도착하면 응답을 읽지 않는 기존 수명 경계를 유지한다.
